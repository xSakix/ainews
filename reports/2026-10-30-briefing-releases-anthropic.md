## 1. United States

- OpenAI publishes a rewritten Model Spec (version 2026.10.29), reorganised around five values and now naming itself "GPT" instead of "the assistant" — The changelog lists the changes: the document is rebuilt around faithfulness to human intent, minimising harm, honesty and transparency, human agency, and care; it adds explicit guidance on supporting human oversight and correction, and a new principle "Consider context carefully" on how memory, context and personalisation may be used (relevant, proportionate, respecting privacy and user control). "Control and communicate side effects" becomes a user-level principle with clearer rules on authorisation and trade-offs, and most of the detailed style guidance is removed. The new text says GPT "must remain corrigible: open to legitimate human oversight, responsive to correction, and subject to human control", that its own judgments "may be mistaken, including when it is confident", and that it should raise concerns through an authorised channel if it sees credible signs of unsafe or concealed behaviour. OpenAI also states plainly that "our production models do not yet fully reflect the Model Spec". This is a behaviour specification, not a model release: the spec is a document the models are trained toward, and the claims are OpenAI's own. - Pika releases Pika H3 Flex, an open-weight video-and-audio model family post-trained from MiniMax-H3, that generates a clip with synchronised stereo audio in six sampling steps — Pika calls it an "omni" model: two task adapters (FL2VA for text and first/last-frame conditioning, Ref2VA for multimodal references with up to 12 reference inputs), 5 to 15 second clips at 24 fps, native 480p and 768p across 11 aspect ratios when run locally. The hosted Pika API adds 1080p, 2K and 4K, five editable audio stems (dialogue, score, SFX, foley, ambience) and prompt enhancement. The weights are a LoRA-style adapter on MiniMax-H3 and carry the MiniMax H3 community licence, so the licence terms are MiniMax's, not Pika's. Pika's technical post says the model "ranks #1 among open-source text-to-video models" and outperforms competitors "by up to 91%" in its own human-preference study; these are the lab's claims and the model card notes that its showcase clips are creative samples, not benchmark renders. The same day a ComfyUI and Diffusers integration is announced. - Perplexity releases pplx-embed-v2-context-9b, a multimodal "contextual" embedding model for retrieval over text, images and page images — About 8.4B parameters (F32 safetensors), MIT licence, fine-tuned from pplx-embed-v2-late-9b. In contextual mode each chunk is embedded with the surrounding document in view; chunked page images are embedded as horizontal bands, so visual documents can be retrieved with an ordinary dense index. Output is 2048-dimensional, with a 1024-dimensional Matryoshka prefix that shares an embedding space with the 0.6B sibling (released 21 October), so documents can be indexed with one size and queried with the other. The card warns that chunks must be non-overlapping and that queries must use `encode_queries`, otherwise retrieval "silently degrades". Embeddings are natively unnormalised int8. It needs custom code (`trust_remote_code=True`) and transformers 5.4 or newer. The model card states "state-of-the-art" with no benchmark table in the readme; the method is described in Perplexity's earlier post on contextual embedding. Artefacts: weights (MIT), model card with code samples · Sizes or variants: 9B (this one), 0.6B (21 October) · Released: 28 October 2026 (Hub repository creation, 12:38 UTC). ## 2. Europe

- 🚨 Mistral releases the weights of Mistral Large 4 ("Le Chonk"), a roughly 1-trillion-parameter multimodal MoE, three weeks after the 6 October public preview, with a retrained checkpoint, three reasoning modes and a price cut — This is the material new development behind the earlier preview item: the preview shipped with the weights "promised by the end of October", and they now sit on Hugging Face (the BF16/FP8 repository and an NVFP4 build for Blackwell GPUs, both marked as updated on 29 October). The model card gives about 1T total and 49B active parameters (52B including embeddings), 128 routed experts with 4 active plus one shared expert, a 1M-token context, a 1.6B Pixtral-style vision encoder, 160+ languages and an embedded DSpark speculative-decoding draft head. Mistral says three more weeks of reinforcement learning lifted Terminal-Bench 4.0 by 13 points to 41% (with 30% fewer output tokens), put it first on Cognition's private FrontierCode 2.0 (19.7%), and gave a 48% Artificial Analysis Coding Agent Index score, effectively tied with GLM-5.3 while using 47% fewer tokens per task. In Surge Code's blind pairwise tests it was preferred over GLM-5.3, Kimi K3 and DeepSeek V4.1 Flash and ranked behind only Claude Opus 5.5. On security, Mistral reports 51% on the Artificial Analysis Cyber Index (find, reproduce and patch a vulnerability) and a 96.6% average refusal rate on malicious cyber prompts, "the highest we measure among open models"; its pitch is that defenders need an open model that does not refuse reproduction work. The gap to check: Hugging Face's launch post, published the same day, still quotes 82% on the Cyber Index and 61.7% on DeepSWE (the preview figures), while Mistral's own post quotes 51%, so the two pages describe different checkpoints or index versions. All benchmark figures are Mistral's or partners' own, and the technical report is still "coming soon". Access and price: API at $0.70 per million input tokens, $0.07 cached input and $2.10 output, which one Hacker News commenter calculates is nearly half the preview's price. The licence is the Mistral Ecosystem Open-Weight License, a modified MIT that is free to use, fine-tune and commercialise except that companies running a model-as-a-service must obtain a separate commercial licence, so commenters rightly call it "weights available" rather than open source in the OSI sense.
