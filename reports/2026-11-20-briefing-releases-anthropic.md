## 1. United States

- Microsoft MAI Code 2 and MAI Code 2 Flash — Announced at Ignite on 17 November: two enterprise coding models, now in GitHub Copilot, with Flash in limited-access preview in Microsoft Foundry and OpenRouter, Vercel, OpenCode and Kilo "soon". Microsoft says (own evals on its MSBench with Copilot CLI, at max reasoning effort) that Code 2 reaches 98% of GPT-6.1 Sol's score at 40% of the cost and 96% of Claude Opus 5.5's at 5% of the cost, and that blind frontend raters (258 annotators) preferred its output over GPT-6 Sol 64% of the time. The price comparisons use a 50% promotional price, so the cost ratios flatter it. A Flash variant was further tuned into "MAI Work Flash" for Microsoft 365 and FabricIQ. Why it matters: a platform owner that resells rivals' models now ships its own cheaper coding model into the tool most developers already use. The release-desk URL is new; the model name appeared earlier only in economy/community briefings. ## 5. Tools, APIs and platform updates

- Gemini API tool retrieval (preview) — On 19 November the Interactions API gained server-side tool search: mark tools with `defer_loading: true`, add a `tool_search` tool and Gemini loads only the function schemas it needs (or run your own retrieval with `execution: "client"`); remote MCP servers support `defer_loading` too. It works with Gemini 3.6 and later, including all Gemini 4 models. Why it matters: large tool sets stop costing tokens on every request, which is the main context cost in agent setups. Same changelog day: Genie 4 (`models/genie-4`) generally available at $1.50/$9.00 per million text tokens and about $0.10 per second of video, which was reported earlier. Artefacts: API feature, docs · Released: 19 November 2026. Source: https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/

- OpenAI gpt-live-1.1 — Update to the Live voice model announced on 19 November in the API changelog: improved pronunciation, accent consistency and transcription in multilingual voice conversations, plus a "standby" setting for GPT-Live-1 and 1.1 WebRTC sessions that pauses inference during silence and resumes when someone speaks (a direct cost lever for voice agents). Competes with the Microsoft and AssemblyAI voice releases above. Artefacts: API only · Sizes or variants: gpt-live-1.1 · Released: 19 November 2026. Source: https://platform.openai.com/docs/changelog

- AssemblyAI STT 3.7 family — Three speech-to-text models published 18 November (AssemblyAI is a speech vendor rather than a general lab, included as a platform update): STT-3.7-Realtime ($0.30/hr), STT-3.7-Realtime-Agent for voice agents ($0.45/hr, unchanged) and pre-recorded STT-3.7 ($0.21/hr, unchanged), 32 languages with auto-detect. Own claims: 3.23% short-form English WER in realtime, 4.53% on 12,460 agent calls, 10.7% diarisation error against 12.0% for ElevenLabs Scribe v3. Universal-3.5 Pro Realtime retires on 1 February 2027. Artefacts: API only · Released: 18 November 2026. Source: https://www.assemblyai.com/blog/introducing-assemblyai-stt-3-7
