- Emergency-AI: an offline survival knowledge base with an optional local chat model — A fork of a Brazilian project that bundles guides on water, food, shelter, first aid, repairs and energy (English, Portuguese, Spanish) and lets you add your own documents. - Dettato: a 20M-parameter audio-to-MIDI model, claimed 60x more efficient — KobiMusic says the model is about 65x smaller than the 1.3B MuScriptor and scores a composite F1 of 60.8 on its own benchmark, against 56.1 for the closed Mirelo A2M v1.1 Pro, 47.4 for MuScriptor and 45.7 for YourMT3+. Training used synthetic instrument audio, CC-licensed solo recordings from URMP and about 20 soundfonts blended with the author's "soundfont babies" technique, and no copyrighted recordings. The author argues the bottleneck is architecture, not data, and proposes a "pitch-lane model" that treats transcription as a local problem. Instrument separation is weak and the output is MIDI, not sheet music. All figures are the builder's own. ## Open-source projects and tools

- Coral v1: a self-hosted gateway where agents write and save their own tools — An open-source "execution rails" layer between agents and the systems they call. Each tool call is checked against a workspace policy (Allow, Ask or Block), credentials are injected, and runs are attributed to the person or agent that started them. Agents send short TypeScript programs through one exec tool; these run in V8 isolates, can chain several tools and filter results, and a successful program can be saved as a private tool (coral.private.name) and shared as coral.shared. The core is Rust, with SQLite or Postgres. The README says it began while the team built an AI SRE agent, and v1 replaces the older 0.x SQL interface. It claims about 37% fewer tokens and 29% less time on 34 GitHub, Linear and Slack tasks with Opus 5.5 (the project's own benchmark, unverified), and also claims ISO 27001 certification and 450+ company users. The repository is older than this week (1,547 commits); the Show HN is the item. Built by: the withcoral organisation · Artefacts: code (Apache-2.0, ee/ directory under a separate licence) · Signal: about 5.0k stars, 52 points and 24 comments on Show HN. Source: https://github.com/withcoral/coral

- OpenCode Browse: an MCP server and Chromium extension that gives coding agents your real browser — Agents open background tabs in collapsed groups inside the browser you already use, with your logins and extensions, and can read, click, type, screenshot and record. For logins, 2FA or payments the agent hands the tab back until you press Continue, and an "Allowed sites" list limits where it goes. It works with any MCP client (OpenCode, Claude Code, Cursor, Codex, Zed) and Chrome, Edge, Brave, Arc, Vivaldi, Opera and Chromium. The source is linked at anomalyco/browse; the page gives no licence or date. Built by: Anomaly (the OpenCode team) · Artefacts: code (licence not stated on the page), Chrome Web Store extension · Signal: 137 points, 62 comments on the HN front page (16 Nov). Source: https://opencode.ai/product/browse

Each bot is a real agent running on the Claude, Codex or Grok CLI on your machine, with its own personality, model, connected apps (via Composio) and computer: a cloud Linux desktop from Boat (paid after trial), a local VM, or your own machine after opt-in. Stack is TypeScript, React 19, Electron and a local harness server on 127.0.0.1:8799 that owns the agent processes. Creation date is not stated; it is in GitHub's weekly trending, so treat the window as unverified. Built by: Milind Soni and contributors · Artefacts: code (Apache-2.0, enterprise/ folder source-available) · Signal: 24.3k stars total, 4,737 this week. Source: https://github.com/milind-soni/OpenMausBot

- Cutcraft: a video editor where the edit is a TSX file the model writes — Clips are cut by meaning (a transcript word or a camera shot) instead of seconds, so titles stay attached to their words when clips are trimmed. A bundled Agent Skill teaches a coding agent to write, check, review stills and render. cutcraft inspect prints the timeline as text, look produces a contact sheet of key frames, and where reports on-screen positions in pixels, so the model can check its own work. - Hotline Computer: a rootless Linux desktop container for a coding agent — One container holds Xvfb and Mesa, Chromium driven over DevTools, D-Bus and AT-SPI (so the agent can read native apps), gnome-keyring, and Nix to prepare per-workspace toolchains. A supervisor exposes an MCP server on 127.0.0.1:8787 with eight tools (capture, input, browser, shell jobs, files, windows, wait, state). The docker run command drops all capabilities and uses a bearer token; you can watch and take over the mouse in the browser. Licence not stated on the page. Built by: 1broseidon (Hotline) · Artefacts: code on GitHub, container image · Signal: 2 points (Show HN, 17 Nov). Source: https://computer.hotline.dev/

- llmtee: a self-hosted proxy that logs the cost of every LLM call — Point your client's base URL at it and it records tokens, cost, latency and time to first token for OpenAI, Anthropic and OpenAI-compatible backends (OpenRouter, Ollama, vLLM, Groq). Per-key daily and monthly budgets return HTTP 429 once hit. Viewable through a web UI, CSV, Prometheus or an MCP server. Single Go binary with SQLite or Postgres, prices from LiteLLM. Deliberately not a gateway (no routing or fallbacks), version 0.x. Response bodies are logged by default with 30-day retention. Built by: garritfra · Artefacts: code (Apache-2.0) · Signal: 19 stars, 10 points. Source: https://github.com/garritfra/llmtee

- asitis-agent-tools: a read-only linter for CLAUDE.md, AGENTS.md and SKILL.md — Checks frontmatter, name and description rules, length limits (200 lines for CLAUDE.md, 500 for SKILL.md), Codex's 32 KiB budget, broken links and @imports, and contradictory rules. It estimates the tokens loaded per file at session start and flags hidden content (instruction-like HTML comments, invisible Unicode, bidi controls). It also detects drift, such as an AGENTS.md that Claude Code ignores because CLAUDE.md shadows it. Fixes are shown as diffs for you to apply. Built by: Katta041 · Artefacts: code (MIT) · Signal: 2 stars. Source: https://github.com/Katta041/asitis-agent-tools

- deslop: a Claude skill that removes LLM-prose tells using linguistics research — Rules are drawn from corpus-linguistics and psycholinguistics comparisons of human and model text (Reinhart et al. 2025, Clark, Martin and Mahowald 2026, HC3 and others) and checked against three public corpora. The skill picks a genre and reader, scans for flagged patterns, revises from content to punctuation, rescans and verifies that numbers, code, links and negations survived, stopping when the text reaches the human range. The core scanner needs only Python 3; model-based tools need spaCy and torch. Effectiveness claims are the author's. Built by: etodanik · Artefacts: code (project's own licence, bundled data CC BY/CC0) · Signal: 18 stars, 11 points. Source: https://github.com/etodanik/deslop

## Experiments, demos and write-ups

- Dead-forms-study: 27 of 105 AI-built contact forms said "sent" and sent nothing — A harness drove public Lovable and Bolt sites with Playwright, filling visible fields with test values (never honeypots), pressing send and blocking every outgoing request so no message reached a site owner. Result: 27 of 105 showed a success message without sending, 54 sent the typed message; among sites without demo signs, 16 of 73 were fake. Rules were written before testing (PREREG.md) and 23 fixture pages with known answers validate the harness. The site list is not published, so the per-site results cannot be checked. Built by: Formgong · Artefacts: code, method and results (MIT) · Signal: 4 points. Source: https://github.com/formgong/dead-forms-study

- Spaceship IDE: a demo of steering LLM text in near-realtime — Explores interfaces for models running at about 60 FPS: a focus monitor showing what the model attends to, attention lock to bias later output, future-vector steering that decomposes a task into eigenvectors, and scrubbing through alternative generations. Uses speculative generation with cache invalidation tied to user actions; the live demo runs on Cerebras and Gemini keys kept in browser storage. Linked to a thesis at the MIT Media Lab; the author used Claude Code for most of the implementation. Built by: Chuanqi Sun · Artefacts: code (MIT), live demo · Signal: 223 stars, 8 points. Source: https://github.com/chuanqisun/spaceship
