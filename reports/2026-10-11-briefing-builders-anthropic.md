## Local models and agents

- Voxlocal: a minimal, fully local voice agent in Rust (macOS) — Sam Khawase wrote a 16-minute walkthrough of a CLI voice agent whose every stage is inspectable. Mic audio goes to Whisper (whisper-rs, greedy decoding), then text normalisation, cosine-similarity retrieval over local documents, an LLM that picks an action, plain Rust tool calls and Piper speech synthesis. It deliberately skips streaming and voice-activity detection to keep the pipeline readable, and is scoped to an automotive-service demo ("how much does an oil change cost?"); the author says not to use it in production. Built by: Sam Khawase · Artefacts: code (repository linked from the post, licence not verified) + write-up (9 Oct 2026) · Signal: Lobsters /t/ai, 10 Oct. Source: https://samkhawase.com/blog/voxlocal-minimal-voice-agent/

## Open-source projects and tools

- Gluon: control platform for coding agents — A TypeScript/Bun terminal tool that runs Claude Code, Codex, Antigravity, Grok Build, OpenCode and Kimi Code side by side in one frame on your own keys. It works out a spec with you and routes each session to a harness x model x effort combination by configurable rules, with cost and context analytics. Interesting as an attempt to treat agent harnesses as interchangeable, cost-routed backends; routing quality is the author's claim. Built by: fidipro · Artefacts: code (Apache-2.0), installer and releases · Signal: ~52 GitHub stars, repo created 7 Oct. Source: https://github.com/fidipro/gluon
- DocFlare AI: free-tier RAG chatbot for docs sites — One script tag adds a streaming "chat with your docs" widget with source chips. The whole stack is Cloudflare-native: Workers + Hono for crawl/API, Workers AI (bge-small embeddings, bge-reranker-base, llama-3.1-8b-instruct-fp8), Vectorize, D1 and cron triggers, with an admin page for sitemaps and a log of user questions. Built by: p10node · Artefacts: code (MIT), deploy button · Signal: ~37 GitHub stars, created 7 Oct. Source: https://github.com/p10node/docflare-ai

## Agents and automation

- Talorys: a personal AI agent that lives in your own Cloudflare account — Single-user assistant with streaming chat, durable editable memory, tasks/notes/projects (also driven from chat) and reminders on Durable Object alarms. Architecture: React on Pages, a private Worker with no public URL behind a service binding, a Cloudflare Agents SDK Durable Object with SQLite, and Workers AI (@cf/zai-org/glm-4.7-flash) for tool calling; deploys with `npx create-talorys@latest`. Non-AI features keep working when the free AI quota runs out. Built by: rociiu · Artefacts: code (MIT), one-command installer · Signal: 253 HN points (front page), ~400 GitHub stars within a day; repo created 10 Oct. Source: https://github.com/rociiu/talorys
- Dori mode: an always-on messenger agent that supervises coding-agent sessions — A skill plus a small Bun/TypeScript CLI (`dori`): you talk to one Telegram, Discord or Slack bot, and it spawns each job in its own agent session in a herdr terminal tab, tracks every session it started and only closes one after the work is actually done (PR merged, issue closed). Labelled experimental; built for the OmO agent harness, with a host guard for load, disk and memory on macOS. Built by: sisyphuslabs · Artefacts: code (licence not verified), skill + CLI · Signal: ~69 stars, 60 forks, created 7 Oct. Source: https://github.com/sisyphuslabs/omo-dori-mode-experimental

## Experiments, demos and write-ups

- AnswerUI: open-source take on ChatGPT's "Intelligent UI" — Answers arrive as interactive interfaces (charts, forms, calculators, live 2D/3D scenes) rather than text. The model streams the UI in "OpenUI Lang", each scene runs as a sandboxed code island two-way bound to the answer's state, so moving a slider updates the text. Works with any OpenAI-compatible endpoint, cloud or local (Ollama); the demo GIFs use Kimi K3 output. Built by: 0xcro3dile · Artefacts: code (MIT), `npx answerui-app`, demo videos · Signal: ~28 GitHub stars, created 7 Oct. Source: https://github.com/0xcro3dile/answerui
