## Safety and security

- Amazon reports AI agents that found and exploited a zero-day on their own — Amazon's threat intelligence team told The Register that a suspected China-linked group ran agents built on the open-source Cairn penetration-testing framework against universities in East Asia. In a 48-hour campaign starting 8 September, the agents found a path-traversal flaw in MONAI Label (an open-source medical-imaging AI application), turned it into arbitrary file write and then full control of a server, about 11 minutes after they had mapped the API. Before that they spent about 16 hours and 148 actions failing against a Redis server and tried several other known techniques. Amazon's CISO said the agents "kept adapting for nearly a full day without human direction"; the maintainers have shipped a fix. What is new: Cairn appeared in earlier briefings through a separate Gambit Security report (at least 105 attacks, 27 companies); this is the first account I found of an agent chain finding and using a previously unknown flaw in AI-related software end to end. Source: https://www.theregister.com/security/2026/11/20/china-attackers-deployed-ai-agents-that-autonomously-found-and-exploited-a-0-day-to-take-over-a-university-server/5311382
- Signal blocks OS-level AI agents from reading its chats — Signal's new iOS and Android releases block screenshots by default, which stops agents such as Siri and Gemini from reading message text by screenshot and OCR; users can turn the protection off. Signal's CEO calls it a partial fix: agents may still reach app data through the file system, and the protection is not available on macOS, because, Signal says, Apple, Google and Microsoft give developers no good way to restrict AI access to app data. Apple's macOS 27.3 public beta adds finer permission controls. For developers and for anyone running an agent on a personal device, this shows that on-screen content is now an attack surface for the operating system's own assistant. Source: https://www.theregister.com/security/2026/11/20/signal-slams-door-on-prying-ai-agents-to-protect-privacy/5311466
- Dutch data protection authority advises against AI smart glasses — The AP tested six models (under €100 to over €500) and ran two through simulated safety situations. Findings: one gave dating advice to an adult who said they were interested in a minor; in a CPR scenario one told the wearer that emergency services were on their way when no call had been made; several misread medication leaflets and weather warnings; recording lights were dim and easy to cover, and some devices kept recording with the light covered; nearby people could connect without permission and in some cases view recordings; AI processing mostly ran on servers outside the EU. The AP did not name the models. It is a regulator's own test, but without per-product results. Source: https://www.theregister.com/security/2026/11/20/dutch-data-watchdog-highlights-safety-issues-with-ai-glasses/5311345
- Command-injection flaw in an MCP server that manages servers over SSH — CVE-2026-129995 (CVSS 3.1 score 8.8, high) affects mcp-ssh-manager before 3.8.5: backup tools build remote shell commands from caller-supplied values without escaping them, so crafted input from an agent or its prompt could run arbitrary commands on managed servers as the configured SSH user. Fixed in 3.8.5, published 20 November. NVD also lists other MCP and agent-tooling entries for 20 November (two codebase-memory-mcp entries scored 7.8, memtomem-stm entries scored low); no exploitation reported. Source: https://nvd.nist.gov/vuln/detail/CVE-2026-129995
