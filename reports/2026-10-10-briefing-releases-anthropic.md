## 1. United States

- Strands decider v1 (Amazon / Strands Agents) — Five open "decision models" for agent workflows, released 9 October as LoRA adapters plus a small readout head on Gemma 4 (E2B, E4B, 12B, 26B-A4B) and Qwen3.5 (2B). Unlike a text-generating LLM, a decider answers typed questions about a state (yes/no, pick one of N options, a level on an ordered scale) and attaches a calibrated confidence, aimed at routing, tool selection, argument checks, triage and guardrails inside an agent. Training uses about 123k rows from 25 public Hub datasets plus 12k code-task rows, with Qwen3.5-4B as teacher, a soup of three seeds and temperature calibration per question type. The model cards report (Amazon's own numbers) JevBench public 200/231 for the 12B and 207/231 for the 26B-A4B (ECE 0.061 and 0.051) and list the weak spots: long multi-step documents, and `score`/`noul` questions unlike the training mix. It sits in the same new category as Liquid AI's d1 models (covered 8 October) and runs locally via `pip install` of the strands-decider package; the weights are mirrored under amazon/ and StrandsAgents/. ## 2. Europe

- ColGrep Agent 2B (LightOn, France) — A 2B Llama-family code-localisation agent (131k context) that powers `colgrep --agent`: given a question about a repository, it combines semantic and regex search with a read-only interpreted terminal and returns file and line ranges. It is meant to run locally as a search sub-agent for a bigger coding agent (hooks for Claude Code, Codex and OpenCode are installed by colgrep). LightOn's example session takes 9 turns and about 22 s on an M3 Pro with Metal, 75–90 s on CPU, 3–4 GB peak memory; the sampling seed is fixed so the same question gives the same answer. Only the Q8_0 file was evaluated through colgrep; no benchmark numbers are given on the card and no licence field is set on the model page, so the licence is unverified. Artefacts: weights as GGUF (Q4_0 to BF16, 1.5–5.0 GB; licence not stated) / model card / code (colgrep CLI on GitHub) · Sizes or variants: 2B, seven GGUF quantisations · Released: 9 October 2026 (Hugging Face upload 09:07 UTC). ## 3. China

- Qwen-Image-2.1-Turbo (Alibaba Qwen) — An 8-step accelerated checkpoint of Qwen-Image-2.1 (covered at its September launch; the Turbo checkpoint is the new part) for text-to-image and image editing. It keeps the same 7B visual-generation architecture, uses CFG=1 and prefix KV caching that reuses text and reference-image context across denoising steps, and ships its recommended sigma schedule inside the checkpoint. It needs Diffusers from source (pipeline-configured sigmas, PR 14950) and transformers 5.17 or later; supported presets run from 1536×2752 to 2752×1536 and 2048×2048, and the card shows a 1680×2512 poster with dense on-image text. The licence is "qwen-research" (not Apache 2.0), so check it before commercial use. Artefacts: weights (qwen-research licence) / model card / code (QwenLM/Qwen-Image-2.1) · Sizes or variants: 7B, 8 steps · Released: 9 October 2026 (Hugging Face 04:50 UTC). Source: https://huggingface.co/Qwen/Qwen-Image-2.1-Turbo
- Youtu-Parsing-Omni (Tencent Youtu) — A 5B omni-modal parser that turns a document page, natural image, chart, flowchart, geometry figure, audio clip or video into one structured JSON schema (layout, text, LaTeX/OTSL tables, Mermaid flowcharts, timestamps, ASR, captions). It uses a single encoder, initialised from a text LM, for pixels, log-mel audio and interleaved audio-visual video, with a few "fusion layers" that let frames attend to audio of the same instant, and is post-trained with an on-policy self-distillation scheme (OSAD) over a shared schema. Tencent's own results: 96.96 overall on OmniDocBench v1.6 (above TeleOCR 96.91 and PaddleOCR-VL-1.6 96.34) and 75.08 average on OmniParsingBench, best open-weight model there and second to Gemini-3-Pro at 77.44. The technical report PDF is in the GitHub repo (the card still says "coming soon" in one place); evaluation code is not yet released; the licence is a custom "youtu-parsing" licence. Artefacts: weights (custom licence) / technical report (PDF in GitHub) / code (vLLM plugin, inference examples) · Sizes or variants: 5B · Released: 9 October 2026 (Hugging Face 06:42 UTC). Source: https://huggingface.co/tencent/Youtu-Parsing-Omni

## 5. Tools, APIs and platform updates

- Claude Managed Agents: dynamic workflows (Anthropic, beta) — Announced 9 October in the Claude Platform release notes. An agent can now write a "workflow", a program that runs many agents in phases and combines their results, for work too large for one conversation such as reviewing hundreds of documents. The server runs it in the background as a workflow run, visible as `workflow_run.*` events on the session event stream, with agents working in server-created session threads. Enable it with the beta header `managed-agents-2026-04-01` and set the agent's `multiagent` field to `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}`; the system prompt should say when to start a run. Only the agent starts a run, and archiving the session can end one. Artefacts: API feature plus documentation · Released: 9 October 2026. Source: https://platform.claude.com/docs/en/managed-agents/workflow-runs
