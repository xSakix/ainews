## United States

- 🚨 Anthropic launches Claude Fable 5.2 and a restricted twin, Claude Mythos 5.2, with a 20% lower list price than 5.1 — Both models have a 1M-token context window, 128k maximum output, always-on adaptive thinking and the tokenizer introduced with Opus 4.7. List price is $8 per million input tokens and $40 per million output tokens, against $10 and $50 for Fable 5.1 and Mythos 5.1. A new fast mode (up to 2.5x output speed, per Anthropic) costs $16 and $80. Fable 5.2 is open to all API customers; Mythos 5.2 has the same capabilities but only for organisations verified through Anthropic's programmes such as the Cyber Verification Program. Anthropic's docs say to start with the latest Opus model and move to Fable only when Opus at higher effort still fails your evals. Two changes can break integrations: the thinking-block "prefix check" now applies to every account (an edited earlier turn returns a 400 error), and the old `computer_20251124` computer-use tool errors on every platform except Amazon Bedrock. The independent number: Artificial Analysis puts Fable 5.2 (max effort) first of 74 models on its Intelligence Index with 65, against a median of 40, but also 71st of 72 on time to first answer (216 s), at $26.54 and 46.4 minutes per index task and 275M output tokens against a median of 72.8M. So the gap is between the top score and a model that is slow, verbose and priced in the expensive tier. Claude Code 2.1.321 already makes it the default Fable model. Artefacts: API only (no weights); model docs and release notes; no technical report seen on the Anthropic news page at the time of checking · Sizes or variants: Fable 5.2 (`claude-fable-5-2`), Mythos 5.2 (`claude-mythos-5-2`), fast mode · Released: 9 November 2026. Source: https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2 (independent scores: https://artificialanalysis.ai/models/claude-fable-5-2)

- Meta releases Muse Ember, its smallest model, for sub-agent work, at $0.10 input and $0.50 output per million tokens — Muse Ember accepts text, image, audio and video and is positioned for the repeated work in an agent harness (tool calls, coding subtasks, routing, extraction, long documents), to be paired with the larger Muse Wonder or Muse Spark for planning. It is proprietary: it runs through Meta's Model API and Muse Code, and no weights were published. Prices rise to $0.30/$1.50 above 200k input tokens. Meta's own table, built on Artificial Analysis data, has it at 36 on the Intelligence Index, level with Claude Haiku 5.5 at max effort (36) and above GPT-6 Luna (28), at an estimated $0.136 per task against $0.411 for Haiku. These are Meta-selected comparisons; Artificial Analysis lists the model as released 9 November. On the local-model forum the reaction was that Meta promised to open-source its models but keeps this one closed. Artefacts: API only · Sizes or variants: one model, parameter count not stated; 200k-token pricing tier · Released: 9 November 2026. Source: https://research.meta.ai/blog/muse-ember

- Zyphra releases ZONOS3-Mini, an Apache-2.0 text-to-speech model that runs in a browser — A sparse mixture-of-experts model with 800M total and about 100M active parameters, 15 Hz dual-codec frames at 44.1 kHz, zero-shot voice cloning and word-level control of delivery. Zyphra reports under 570 ms to first audio in the browser on a Pixel 9 and under 150 ms on an M3 MacBook Air; the model card gives 80 ms median time to first audio on one H100 with 8 concurrent requests. It was trained on 112 H100s in 2.5 days. Runtimes ship for WebGPU, SGLang, vLLM, GGML, MLX and CUDA; the hosted version is on Zyphra Cloud. Quality claims rest on Zyphra's own new ZTTS2-Eval benchmark. Artefacts: weights (Apache-2.0), code, blog post with architecture and evaluation · Sizes or variants: 800M total / ~100M active; GGUF and WebGPU builds · Released: 9 November 2026. Source: https://www.zyphra.com/our-work/zonos3-mini

## China

- Baidu publishes ERNIE Evolve, an automated AI-research system that beats public records on two training benchmarks — Given a code repository, an objective and evaluation criteria, the system runs two nested loops (a "director" picks research directions, parallel lanes modify code and submit it for independent evaluation) and keeps what survives review. Baidu's own table: on NanoChat AutoResearch it reaches validation bits-per-byte 0.8763 against the previous best 0.8878; on NanoGPT Speedrun Track 1 it reaches the target loss in 38.9 s against 39.9 s, and on Track 3 in 2,590 steps against 2,690; on SOL-ExecBench its mean score is 0.819 against 0.827, so it did not beat the best there. Baidu also says changes it found for inference of the in-development ERNIE-5.5-Flash passed production validation, and frames this as a first step toward recursive self-improvement. The optimised results are on GitHub; the system itself and its weights are not released. These are Baidu's measurements. Artefacts: technical blog post, open-sourced benchmark results; system not released · Sizes or variants: not applicable · Released: 9 November 2026. Source: https://ernie.baidu.com/research/posts/ernie-evolve/

- Ant Group's Robbyant releases LingBot-Touch, open tactile-sensing encoders for dexterous robot hands — A JEPA-style model that learns from three kinds of touch signal (magnetic, piezoresistive, visuotactile) through modality-specific tokenizers and a shared transformer, predicting in latent space. Two bundles (small and tiny) hold only the frozen encoder weights and a config; the inference code, sensor adapters and downstream heads are distributed separately, so the weights alone are not enough to run it. No benchmark numbers are on the model card. Artefacts: weights (Apache-2.0), encoder only · Sizes or variants: LingBot-Touch-Small and LingBot-Touch-Tiny · Released: 9 November 2026. Source: https://huggingface.co/robbyant/lingbot-touch-small

## Tools, APIs and platform updates

- IBM Research and Red Hat contribute the Praxis Policy Engine to the open-source Praxis AI gateway, now in the CNCF Sandbox — The engine treats tools, prompts, resources, model calls and other agents as explicit policy targets, and writes a signed, hash-chained audit record per decision in the OCSF security-event schema. One policy specification can be enforced at a gateway, beside an agent or inside a framework; IBM is also working with CoSAI on a standard for agent identity and bounded delegation. This is a technical note, with no measurements, but it shows where enterprise control over agents is being built. Artefacts: open-source code, technical note · Released: 9 November 2026.
