## Local models and agents

- Folate: a 107 MB CPU-only DOM element ranker for browser agents — Folate fine-tunes google/electra-base-discriminator on Mind2Web as a cross-encoder that scores (query, DOM element) pairs, then quantises it to INT8 ONNX (about 180–250 MB runtime RAM) so an agent can pick page elements without a 7B vision model and while sharing a small machine with a headless browser. The README reports Top-1 of 93.3% (unseen tasks), 88.9% (unseen websites) and 92.1% (unseen domains) over 6,037 Mind2Web steps, at 2.3–4.3 s per step on 2 vCPUs; the HN title claims it beats 7B VLMs at 1/60th the size, which is the builder's own comparison. Built by: figranium · Artefacts: code (Apache-2.0), Hugging Face model, PyPI package, demo Space · Signal: 2 HN points (Show HN 50507874) Source: https://github.com/figranium/folate

- nano-edge-tts: a 1.75M-parameter replacement for Kokoro-82M's waveform decoder — The text side of Kokoro (pronunciation, timing, pitch, voices) is kept; the 53.3M-parameter decoder is replaced by two small networks that set per-frequency gains on a pulse train and white noise, rendered with inverse STFTs, so no neural network runs at audio rate. The model card reports decoder real-time factor 0.0042 against 0.1378 (33x faster on one CPU thread), whole pipeline 11x faster and 0.75 GB peak memory against 1.4–1.7 GB, and links a short paper that includes negative results; the figures are the author's. Built by: drmhse · Artefacts: weights (Apache-2.0), paper PDF · Signal: 13 HN points, 9 HF likes Source: https://huggingface.co/drmhse/nano-edge-tts

- Yogurt: open-source Granola alternative that records and summarises meetings locally — A desktop app (Mac, Windows, Ubuntu) that captures microphone and system audio with no bot in the call, transcribes live and writes the summary with an open-weight model through llama.cpp. After a one-time model download it works offline, needs 8 GB of memory and no account. The interesting part is the market signal: a funded company (Frigade) giving away what paid meeting-note tools charge for. Built by: Frigade · Artefacts: code (MIT), installers for three OSes · Signal: 305 HN points, 115 comments (Show HN 50454625) Source: https://github.com/FrigadeHQ/yogurt

- Minute: free offline meeting notetaker for Mac using local LLMs — The same idea as Yogurt as a Mac-only app (v1.14.0): record, transcribe and summarise on the machine, nothing leaves the computer. It is not a new idea, but together with Yogurt it shows local meeting notes becoming a commodity category. Built by: mraza007 (per release URL) · Artefacts: code (MIT), macOS app · Signal: 7 HN points (Show HN 50510760) Source: https://minutenotes.app/

- byob: a native desktop "AI coworker" for any OpenAI-compatible endpoint, no Electron — A GPU-drawn native app (about 60 MB, one folder) that points at llama-server, Ollama, LM Studio, vLLM or a hosted API, works in a folder with you and builds spreadsheets, charts and documents beside the chat. The same interface is compiled to WebAssembly so a browser tab or phone shows the identical live session; tool calling falls back to prompt-based calls when the server has none. The README warns it was written heavily with AI agents. Built by: Scronkfinkle · Artefacts: code, demo GIF recorded against llama.cpp · Signal: 3 HN points (Show HN 50507341) Source: https://github.com/Scronkfinkle/byob

- local-agent-bench: stock Qwen3-8B on a Mac against Claude Opus 5.5 on 200 tasks — A self-scored benchmark on Robinhood Chain data with the same frozen retrieval context for both models. On the 100 factual tasks the local 4-bit 8B model matched Opus on numeric fields (197 vs 189 of 200) and citations (197 vs 195), but trailed on complete answers (154 vs 181), correct status (160 vs 192) and passing explanations (19 vs 36 of 50). It is notably candid: one run per model, own scorer, a paired difference of -13.5 points with a bootstrap interval, and a document of contested points. Median latency 2.1 s against 6.4 s; API cost $1.64 for the cloud run. Built by: qvotvm · Artefacts: code and data (MIT), write-up · Signal: 2 GitHub stars at last look Source: https://github.com/qvotvm/local-agent-bench

## Open-source projects and tools

- db-branch: copy-on-write database branches in seconds on your own servers, aimed at AI agents and CI — Uses ZFS clones to give MySQL and PostgreSQL a branch of a large database with nothing copied, so an agent can break, reset or throw away a copy of production-shaped data. Self-hosted, beta, with a console, TTLs and a browser demo; it needs Linux and ZFS (a Multipass cloud-init script is provided for Mac and Windows). Relevant because agents that run migrations or SQL need disposable databases. Built by: db-branch team · Artefacts: code, browser demo · Signal: 34 HN points, 10 comments (Show HN 50506940) Source: https://github.com/db-branch/db-branch

- RealtimeVAD: an earlier "speaker stopped" signal for voice assistants — Kolja Beigel (RealtimeSTT, RealtimeTTS) keeps Silero VAD for speech detection and adds a 10 ms energy check against room noise and the speaker's own level, emitting a pause event. On 3,153 real turns from one speaker he reports a median lead of 92 ms over Silero's probability drop (130 ms in fast mode) and 238 ms before Silero's VADIterator end, with no gain on a distant microphone; start the reply on pause and cancel if speech resumes. Single-speaker data, builder's measurement. Built by: KoljaB · Artefacts: code, demo, results docs · Signal: 33 HN points (Show HN 50474586) Source: https://github.com/KoljaB/RealtimeVAD

- Redacted: strips secrets from tool output before a coding assistant reads it — A hook for Claude Code that rewrites command output, so a `cat .env`, a `git diff` or `kubectl get secret` shows `[REDACTED:aws_access_key ...0001]` to the model. The argument is that deny lists check the command string, while secrets arrive through ordinary output; `redacted init` learns project-specific names. Built by: svn-arv · Artefacts: code · Signal: 1 HN point (Show HN 50513298) Source: https://github.com/svn-arv/redacted/

- Aegis: a Postgres wire-protocol proxy that blocks destructive SQL from AI agents — Sits between application and database, parses each query with a Wasm AST parser and terminates the connection on DROP TABLE or unfiltered DELETE before it reaches the database. Open-source tier is AGPL-3.0, with a Docker image and Python SDK; the README asks for stars, so treat adoption claims with care. Built by: raymondhani · Artefacts: code (AGPL-3.0), Docker image, PyPI SDK · Signal: 1 HN point (Show HN 50509721) Source: https://github.com/raymondhani/aegis-proxy

- turbo-browser-mcp: a Playwright MCP server that batches actions to cut token use — Replaces 25–33 browser primitives with 10 batched tools and returns DOM deltas after a click. The README's own benchmark (tiktoken o200k_base, local Chromium, synthetic dense pages) shows a 140-button page at 1,135 tokens against 18,654 as HTML, and a post-click delta of 56 tokens against 3,582 for a full ARIA rescan. Synthetic pages, author-run. Built by: Tthanh2k6 · Artefacts: code (MIT), benchmark script, 407 tests · Signal: 47 HN points (Show HN 50503930) Source: https://github.com/Tthanh2k6/turbo-browser-mcp

- claudette: run Claude Code against Mistral models — A wrapper that starts a local proxy translating Claude Code's requests to Mistral's API and runs `claude` with its own config directory, showing context use and estimated cost in the status line (the README sample shows a 256k window). The author notes Anthropic does not support non-Claude models, so it is best-effort and macOS-tested only. Built by: raed667 · Artefacts: code · Signal: 3 HN points (Show HN 50508283) Source: https://github.com/raed667/claudette

## Agents and automation

- Taskless: turns corrections you give a coding agent into lint rules that run on every change — You correct the agent once; a skill writes the correction as an ast-grep or Vale rule file in the repo (no account needed locally), and `taskless check` reports file, line and severity and exits 1 for CI. A practical answer to repeating the same AGENTS.md instruction. Runtime checks need an account. Built by: taskless · Artefacts: code, npx installer for Claude, Cursor, opencode and others · Signal: 1 HN point (Show HN 50509741) Source: https://github.com/taskless/cli

- skillroll: Markdown evals for agent skills, with an LLM "Dungeon Master" simulating the world — Each eval states an input, a hidden world state and success criteria (for example "the chest is a mimic; inspect before opening"); a model plays the environment, the agent acts under the skill, and a judge returns an evidence-backed verdict. Tests decisions instead of exact scripts, though judge and simulator are themselves models. Built by: hagaiw · Artefacts: code, authoring docs · Signal: 2 HN points (Show HN 50508503) Source: https://github.com/hagaiw/skillroll

- gavel: guided code review with your coding agent — A skill for Claude Code or Codex in which the agent prepares a brief, explains its choices beside the diff in a browser, splits large changes into focused reviews, and you give a verdict per part and ask questions in threads. Written by the PhotoStructure developer after a long authentication change; MIT, Node 22.20+. Built by: PhotoStructure (Matthew McEachen) · Artefacts: code (MIT), write-up dated 7 Nov (first Show HN this week) · Signal: 2 HN points (Show HN 50512685) Source: https://photostructure.com/coding/gavel/

Built by: taherchhabra · Artefacts: code, browser console, architecture doc · Signal: 2 HN points (Show HN 50507721) Source: https://github.com/taherchhabra/pi-managed-agents-api
