## 2. Tools & Products

- ShadowPEFT lands in Hugging Face PEFT — ShadowPEFT adds a stateful “shadow” network that carries task-specific information across transformer layers, rather than applying independent low-rank weight updates. It is merged into PEFT’s main branch and is intended to support both attached inference with a base model and detached inference using the smaller shadow network. Source: https://huggingface.co/blog/shadow-llm/shadowpeft-peft

- Reef open-sources infrastructure for continually improving agents — The Reef project treats live inference traces, tool results and user feedback as learning inputs, while versioning changes to the model and the wider agent harness. The release matters because most serving stacks separate inference from training and do not manage continuous changes to prompts, memory, skills and orchestration. Source: https://huggingface.co/blog/quao627/your-inference-server-is-secretly-a-learner-reef

- OpenAI Foundation starts Public Data for Health — The foundation announced more than $125 million in an initial tranche of grants for open scientific datasets covering drug properties, failed drug-development records and personalized cancer-vaccine research. The program focuses on data that individual institutions may lack the incentive or capacity to create and make broadly available. Source: https://openaifoundation.org/news/public-data-for-health
