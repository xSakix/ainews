## 3. China

- DeepSeek-V4.1-Flash-1017: an in-place update of the September Flash model, MIT-licensed, with a lab-reported jump on agentic coding — DeepSeek calls it a "minor update" to DeepSeek-V4.1-Flash (10 September) and reports, on its own benchmark table, Terminal-Bench 4.0 31.2 to 42.3, ProgramBench 20.3 to 29.1, Apex Bench 64.6 to 72.1 and HLE without tools 36.8 to 42.6, while saying the model uses fewer output tokens and less task time. The card compares it with Kimi K3, GLM-5.3, GPT-5.6 Sol and Claude Opus 5 and shows the new Flash behind Opus 5 on most rows but ahead of the listed open models; these are DeepSeek's own numbers, with Terminal-Bench run in the Claude Code harness. The API alias `deepseek-flash` now points to the new version at unchanged prices ($0.15 per million input tokens on a cache miss and $0.60 per million output off-peak, double at peak; the legacy `deepseek-v4-flash` names are retired and billed at Flash price), and the web and app models were switched too. The card gives a 1M-token context window, recommends at least 256K max output, ships a reference prompt-encoding implementation instead of a Jinja chat template, and points to a Rust "deepseek-recipe" toolkit. The model page has no parameter count; the safetensors metadata lists about 763B stored values across 48 shards (FP8 plus packed low-bit weights), and the Hugging Face page had 970 likes within a day. An independent early signal: a Nebius engineer who keeps a 10-task coding benchmark built from his own agent sessions reports that the new model passes all 30 runs on "high" effort at about $0.045 per task (against 80% pass-all-3 for the September version on max), but burns about 550K tokens per task versus about 30K for Opus 5.5 on low, so the lab's "fewer tokens" claim has a counter-measurement worth watching.
