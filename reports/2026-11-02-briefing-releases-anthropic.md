## 3. China
- DeepSeek open-sources dsh-superagent, a "proactive" coding-agent prototype built mostly by agents, with a design article on "super-agents" — The MIT-licensed repository packages an agent for DeepSeek Harness that listens to GitHub (and optionally Feishu), opens a work item when an allowed person asks, works in its own session and directory, answers in the original conversation (for example with a pull request) and shows what needs a human in a web panel. The README says it is research code "not an official DeepSeek product", that much of its engineering was done by coding agents, and that some designs in the companion article are not implemented. The article (translated from Chinese) argues that single-session agents are limited by human attention (it says a person can follow only 3 to 5 active sessions) and proposes a Router layer plus isolated Worker sessions, event-driven triggers, multi-channel interaction and a watchdog; it reports DeepSeek's internal instance finds bugs in a group chat unprompted and opens fixes. Bloomberg (paywalled, not read) framed it on 1 November as a rival to Claude Code. The design is the lab's own account; no benchmark or independent test is given.
