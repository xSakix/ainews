## 1. United States

- Anthropic reports that an internal Claude research model designed 17 working protein binders against scorpion neurotoxins, and publishes all 211 tested designs — Over 64 hours the model, working mostly autonomously inside "Claude Science" with four human follow-up prompts, generated 318,484 designs and picked 180 for testing; Anthropic staff added 31. Adaptyv Bio and Twist Bioscience tested all 211 for binding and 17 met the criteria (binding to one of four neurotoxins dangerous to humans). The post is explicit that neutralisation of venom has not been confirmed, so it does not claim an antivenom; two outside experts called it "a promising first step". The prompt was developed with the investment research firm Citrini Research, whose team were non-experts, which is the tension: a motivated amateur group got lab-confirmed binders in days. All results are the lab's own account. - NVIDIA releases Cosmos3-H-Dreams, a real-time surgical world model trained on clinical cholecystectomy video — Given one endoscopic frame, recent robot commands and future kinematic commands for both arms of a CMR Surgical Versius robot, the model generates the resulting endoscopic video autoregressively. It is a few-step causal student (four-step and two-step variants) distilled from a teacher, Cosmos3-H-Embodied-Nano, and NVIDIA says it runs interactively on a single RTX PRO 6000 using its FlashDreams streaming library. The intended use is policy evaluation in simulation and synthetic data for surgical robotics; the blog itself warns that visual realism "is not proof of biomechanical accuracy". NVIDIA calls it the first real-time generative surgical simulator trained on clinical recordings (its own claim). - Cloudflare previews Clairic, an "extraction" model that returns numbers, spans and forecasts in one pass without generating tokens — Clairic is the first of a new class Cloudflare calls System One extraction models, after its Clef decision model. It returns extracted text with character offsets, computed values (dates, durations, amounts), estimated values as a median with an 80% interval, and forecasts of future series values, each with a confidence score, or null when the input has no answer. It is billed for input only and Cloudflare says it typically answers in under a second; accuracy, latency and cost advantages over LLMs are the company's own claims. The post lands one month after TypeSafe's Jev started the "System One" idea, so it is a sign that a non-LLM, typed-output model category is forming. Artefacts: API (hosted on Workers AI as @cf/cloudflare/clairic, preview), blog post; weights announced "soon", not published · Sizes or variants: Clairic, parameter count not stated · Released: 19 October 2026, 17:48 UTC (about 33 hours before this check; included under the 72-hour late-surfacing rule, and not in any earlier briefing). Features: FlashMLA, DeepGEMM and DeepEP kernels plus TileLang kernels, attention data-parallelism with expert-parallel load balancing, DSpark speculative decoding with confidence-scheduled verification, SWA bounded replay, an asynchronous zero-overhead scheduler, batch-invariant and deterministic sampling, and structured outputs (regex, JSON schema, EBNF). ## 5. Tools, APIs and platform updates

- OpenAI adds 12-hour prompt caching to the Responses API — Shared instructions, tools and context can stay cached for 12 hours, so requests hours apart still pay the lower cached-input price. Cache writes at this setting cost 2.5 times the normal input-token price, which means the saving only appears if the same prefix is read often enough; a team with bursty, repeated agent prompts gains, one with one-off prompts pays more. Artefacts: API feature (docs guide) · Sizes or variants: 12-hour cache option; write price 2.5x input · Released: 20 October 2026. Source: https://platform.openai.com/docs/changelog

- Anthropic ships Claude Code 2.1.305 — Adds `sandbox.allowNestedUserNamespaces` so sandboxed Linux commands can create user namespaces (Chromium, rootless podman); the changelog itself notes this lets them get around the sandbox's file protections. It also adds `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` for unattended retry mode to notice a lifted usage limit, fixes a 2.1.304 regression that made every request fail on Vertex, Bedrock and gateways that reject tool search (Claude Code now retries without it), and improves `/usage` with one-line fixes that `f` applies. Artefacts: code (npm package, CHANGELOG.md) · Sizes or variants: 2.1.305 (npm `latest`; `stable` still 2.1.304) · Released: 20 October 2026, 19:29 UTC. Source: https://registry.npmjs.org/@anthropic-ai/claude-code/2.1.305

- Anthropic takes Inference hooks out of beta for Claude Enterprise — Each governed prompt is sent to the organisation's own AI security server before inference; the server returns allow or deny within a configurable timeout (5 seconds by default), and a denied request never reaches the model. An optional "Validate tool calls" setting adds a second hook that fires before any tool call in Claude's response runs. Requests are signed to the Standard Webhooks specification, and the hooks apply across all Claude products in the organisation with nothing installed on user devices. Configuring them needs an Owner role. Artefacts: API/admin feature, docs · Sizes or variants: events `prompt` and `tool_call` · Released: 20 October 2026. Source: https://platform.claude.com/docs/en/manage-claude/inference-hooks

- Amazon Bedrock supports structured outputs for all Anthropic Claude models — Schema-compliant JSON responses now work through both the bedrock-runtime APIs (boto3) and the Messages API on the bedrock-mantle endpoint, removing custom parsing and retry logic for extraction tasks, in every region where the Claude models run. Artefacts: API feature, docs · Sizes or variants: all Claude models on Bedrock, two endpoints · Released: 20 October 2026. Source: https://aws.amazon.com/about-aws/whats-new/2026/10/claude-structured-outputs-bedrock/

- llm-d 1.0 reaches production status for open-source Kubernetes inference serving — IBM Research, Red Hat and Google, the lead maintainers (co-founded with CoreWeave and NVIDIA), announce a stable API, multi-tenant serving with competing priorities and upgrades that do not interrupt service. The release packages techniques that were already in the project: prefix-cache-aware routing, KV-cache offloading, batch inference optimisation, prefill/decode disaggregation and wide expert parallelism for MoE models. The stated argument is cost: with inference bills rising, llm-d is meant to help bring model deployment in-house, on any accelerator and any cloud. The post gives no benchmark figures in the part I read. Artefacts: code (open-source project), IBM Research blog post · Sizes or variants: llm-d 1.0 · Released: 20 October 2026, 12:00 UTC. Source: https://research.ibm.com/blog/llmd-1-0-is-ready-for-production-inference-serving
