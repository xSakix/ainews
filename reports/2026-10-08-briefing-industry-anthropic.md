- **Critical unauthenticated remote-code-execution flaw in LMCache, the cache layer used with vLLM; no fixed version exists (CVE-2026-105192, CVSS 9.8)** — JFrog disclosed on 7 October that LMCache's multiprocess mode, where the cache runs as a standalone server reached over ZeroMQ, unpickles a message before checking its type, so one crafted network message runs code as the LMCache user (root in the project's official container images). Affected: 0.3.9 through 0.5.5 and the 0.5.6 release candidates. It is reachable from other machines only if the operator binds a routable address, but LMCache's own example Kubernetes deployment listens on every interface. JFrog's advice until a patch ships: keep the port on localhost or a trusted cluster network; a firewall reduces but does not remove the risk. Directly relevant to anyone self-hosting vLLM with a shared cache. Source: https://thehackernews.com/2026/10/unpatched-critical-lmcache-flaw-lets.html

- **PoeLLM malware hides its command-and-control address in a poem on GitHub and has infected 3,000-plus exposed LLM servers (Lumen Black Lotus Labs)** — The "Canto Incognito" campaign, attributed with moderate confidence to an Italian-speaking, financially motivated actor, has been running since at least April: it exploits internet-facing LiteLLM, Ollama, Gotenberg and Gitea installs (and an Ivanti Sentry flaw), installs cryptocurrency miners, and turns victims into scanners. Each new C2 changes a few words of the poem and the malware derives the address from them, so the text has no link or payload for a classifier to flag; Lumen calls it the first real-world use of "adversarial poetry" it has seen. About 800 servers per day at the June peak. The Register counts "3,000+", The Hacker News "3,400+"; both quote Lumen. Source: https://www.theregister.com/security/2026/10/07/poetry-is-the-new-ai-security-threat-as-poellm-malware-infects-3k-servers/5301672

- **AWS releases Strands Box, an open-source agent sandbox whose policies can look at what the agent has already done** — On top of OS-level isolation, Box uses the Dogwood Local Engine so a tool call is checked against the agent's history as well as the request (AWS's examples: at most three Slack posts per ten minutes, rules on when a git push is allowed, caps on costly API calls). Strands Shell and Monty for Python route shell and Python operations through the same policy engine, so file deletions and API calls become visible to policy. Marc Brooker says rules are enforced without relying on the agent to obey. A concrete design for the "YOLO mode" problem; AWS's own claims, not independently tested.
