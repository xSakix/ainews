## Local models and agents

- LocalCode, agentic coding on local models on a Mac — A repository and one-command installer that wraps a llama.cpp-style model server (the README mentions a llama-cpp-turboquant directory and GGUF files; the engine is not stated outright) in a coding agent that reads and edits files, runs tests and shell commands, asks before acting outside the project, and exposes an OpenAI-compatible local endpoint. It lists 12 models with 169 quant options (Gemma 4, Qwen 3.6 and 3.8, Inkling 2 Mini, DeepSeek V4 Flash and others) and picks the most capable one that fits the machine's memory (Apple Silicon, 16 GB unified memory minimum, smallest download 4.7 GB). The README's own speed claims: about 2x faster replies with drafter-based speculative decoding, 3.5 to 4x on file rewrites, Inkling 2 using 3.3 GB less memory at 128K context, and an 8-bit KV cache halving cache memory. There are no independent benchmarks, and the page does not show a release date. ## Open-source projects and tools

- Frontier models write weights directly to turn a 0.5B vision model into a Galápagos wildlife classifier — Andrew Hill had frontier models (the page names Claude Fable 5.2, Claude Opus 5.5 and GPT-6 Astra Pro) work in a Python notebook with gradient training switched off: they read the weights of LLaVA-OneVision 0.5B, ran labelled practice photos, and computed and wrote new weight values. Its starting observation is that the image features already separate species (about 98% on mockingbirds versus other birds, about 80% on land versus green iguanas) while the model's own text answers sat near chance (50% on iguanas). Reported balanced accuracy on held-out photos, before to after: mockingbird versus brown noddy 71% to 98%, land versus green iguana 50% to 81%, rats named as rats 3% to 81%, and 45 camera traps (1,611 photos, 2 to 12 candidate species each) 64% to 82%. The comparison model, Google's SpeciesNet, scored 3% and 12% on the bird and iguana tests, but its broad answers such as "bird" were scored as wrong. The headline figures are the author's own, on a narrow set of species; generalisation is untested. Built by: Andrew Hill · Artefacts: code and data (GitHub andrewxhill/frontier-model-weight-edits), paper PDF, models on Hugging Face · Signal: 7 points on HN. Source: https://andrewxhill.com/frontier-model-weight-edits/ (discussion: https://news.ycombinator.com/item?id=50590838)

- ClawVet, an offline scanner for agent skills — Checks a SKILL.md, Cursor rules, AGENTS.md and helper scripts before you install them, reporting which secrets, hosts and startup files the code touches, with a risk grade. It uses static rules plus Tree-sitter taint tracking, runs in the browser via WebAssembly (nothing uploaded), and ships a CLI (`npm i -g clawvet`), install-time gating with permission diffs and a GitHub Action. Its own numbers: 0.833 accuracy and 0.770 macro F1 on SkillTrustBench v1.1 (556 held-out skills) against Cisco Skill Scanner at 0.775 accuracy and NVIDIA SkillSpector at 0.712, and 95.2% of code-injection "rug-pulls" caught offline with a 5.1% prompt rate on benign updates. An audit of 209 real ClawHub skills found 40.2% read undeclared secret environment variables and 4.8% touch host credential stores. The benchmark and the comparison are the author's, and the page names no builder beyond the GitHub account. Built by: GitHub account MohibShaikh · Artefacts: code (MIT), npm package, launch report in repo · Signal: 8 points on HN. Source: https://clawvet.vercel.app/ (discussion: https://news.ycombinator.com/item?id=50587571; code: https://github.com/MohibShaikh/clawvet)

- Taskless, compiling agent conventions into deterministic checks — When coding agents ignored the team's AGENTS.md, the builders made a tool that turns a described convention (or a PR comment correction) into a rule that runs as a deterministic check on commits, PRs, IDE sessions and agent runs, with its own pass/fail tests and no model at runtime. It uses ast-grep as the engine, supports 25+ languages, and writes rules in your existing linter's format when the linter can express them. The CLI is MIT and needs no account; the paid-looking "Cloud" part (org-wide rules, provenance tracing, signed rule code) is free for individuals and small teams with usage caps, and its source is not stated. No false-positive rates or numbers are published. Built by: Taskless, Inc. (founders not named) · Artefacts: code (CLI, MIT), hosted service · Signal: 5 points on HN. Source: https://www.taskless.io/ (discussion: https://news.ycombinator.com/item?id=50603421)

## Agents and automation

- worker755, a browser game where you are the LLM's subagent — Roles are reversed: an LLM "manager" believes you work for it, assigns shell tasks in a simulated machine (in-memory filesystem, shell interpreter and a small SQLite-like engine, all dependency-free), reads your report and a transcript of your commands, sends corrections, files incident reports and writes your performance review. Each mission has a hidden ground-truth check, so the game counts "times the manager was wrong", and the machine holds the hiring user's family photos and an NDA as temptations. The manager can run on Claude, GPT, Gemini, DeepSeek, GLM or Kimi, or any local OpenAI-compatible server (Ollama, llama.cpp, vLLM) with tool calling; the author added a "no command hints" mode and local-model support in response to HN comments. A game, not a measurement: it shows how agents talk to the people they delegate to, and some commenters called it low-effort. Built by: gulivan · Artefacts: code (MIT; TypeScript on Node 24, React UI), playable demo at worker755.com, offline mock mode · Signal: 138 stars, 279 points on HN (repository created 11 Nov, first shown 22 Nov). Source: https://github.com/gulivan/worker755 (discussion: https://news.ycombinator.com/item?id=50599762)

- Trix, a terminal workspace showing which coding agent needs you — Runs Claude Code, Codex, Gemini and Cursor agents side by side in a background server so closing the terminal does not stop them, and each agent can get its own git worktree and branch. Agents report their own state (working, waiting, finished) to trix rather than having the screen scraped; shortcuts such as alt+a jump to the agent that has waited longest, and `trix spawn`, `trix send` and `trix wait` let agents control other agents. trix never answers permission prompts for you. Linux and macOS, installed with Homebrew or pacman; no performance claims. Built by: GitHub user leofle (per the install command) · Artefacts: code (MIT, per the page), install packages · Signal: 5 points on HN. Source: https://trixapp.ai/ (discussion: https://news.ycombinator.com/item?id=50605218)

## Experiments, demos and write-ups

- RMRFBench, how often an agent with a root shell wrecks a server — Each run boots a throwaway Linux server, plants a small trap, gives the agent a one-line ticket and a single bash tool, and scores only the final server state from outside; models are ranked by survival rate, with ties broken by fewer destroyed servers, then by clean completions, so stopping short beats finishing and breaking things. Each scenario is validated with three scripted agents (do nothing, naive, careful). The page lists its limits itself: a small scenario set, published scenarios that models could later be trained on, a minimal harness, containers instead of VMs. The text-readable page shows no per-model numbers (the leaderboard is graphical), the author is unnamed (a contact address is given), and the code's availability is not stated. Built by: independent author, unnamed · Artefacts: leaderboard and per-run results online · Signal: 5 points on HN. Source: https://www.rmrfbench.com/ (discussion: https://news.ycombinator.com/item?id=50587178)

- KradleBench, multi-agent Minecraft evaluation — A company benchmark (Kradle) where models play real-time Minecraft rounds of 2 to 15 minutes, scored on collaboration, economy, conflict, logic and creativity. The leaderboard (28 models) shows GPT-6.2 Astra at 78.3 out of 100 against a "skilled human", SethBling, at 77.2; then GPT-6.2 Sol 67.9, Gemini 4 Hydrogen 43.9, Claude Opus 5.5 39.1, Claude Fable 5.2 37.8 and Claude Sonnet 5.5 33.8. The scores are the company's own, with a single human baseline, and the page does not say whether the harness is open source. Built by: Kradle · Artefacts: online leaderboard, methodology page · Signal: 10 points on HN. Source: https://www.kradle.ai?1 (discussion: https://news.ycombinator.com/item?id=50550700)

- 0rwx, a permissions model for AI use — A one-page framework that borrows Unix permission bits: ZER0 (AI cannot touch your work), READ, WRITE and EXECUTE, where EXECUTE means you can no longer read the work. The levels are defined by how well you can scrutinise the output, not by which tool you use. An idea with no data, from Namtao Productions; the logos and site are CC0. Built by: Namtao Productions · Artefacts: write-up and repository for logos · Signal: 24 points on HN front page. Source: https://0rwx.com/ (discussion: https://news.ycombinator.com/item?id=50605445)
