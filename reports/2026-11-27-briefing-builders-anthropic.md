## Local models and agents

- AMD patch set for llama.cpp roughly doubles prefill on an eGPU Radeon, and the HN thread argues about what the speed costs — "llama-cpp-rdna-boosts" by stew675 is a minimal patch set applied to a pinned llama.cpp commit, shipped as a prebuilt ROCm container image. The author's own table (AMD R9700 on a laptop eGPU, Qwen3.8-27B GGUF at Q6_K_L with MTP) shows prefill going from about 700 to about 1300 tokens/s and generation from about 35 to about 55 tokens/s; the page does not say exactly what the "before" configuration was, notes the code is largely AI-generated and thinly documented, and states no licence. The HN thread (295 points, 73 comments) collects other AMD reports: 27B at Q8 going from about 250 prefill / 25 decode to 600 / 40 on one commenter's card, two MI50s at about 70 tokens/s, and one gfx1103 patch giving only about 15% prefill and 3% decode. Commenters worry that speed-focused forks (fast-math flags, expert-selection shortcuts) change output quality in ways that are hard to measure in long agent runs, and a llama.cpp maintainer says high-quality patches are welcome while others say regression risk is the barrier to merging. Built by: stew675 · Artefacts: patch set + container image (no licence stated), write-up · Signal: 295 HN points. - mac-alpha-zero trains an Othello agent that beats the Edax engine's level-1 setting, in two hours on one Mac — an alpha-stage MLX library for batched Monte Carlo tree search and Gumbel AlphaZero-style self-play, with fused Metal kernels. A 4-block, 64-channel ResNet trained for two hours scores 0.905 against Edax level 1 over 100 games with 32 search simulations per move (90 wins, 1 draw, 9 losses; draws count half) and 0.990 with 128; against Edax level 2 it scores 0.605 at 32 simulations and 0.960 at 512. Full training plus evaluation took 2 h 29 min on an Apple M5 with 24 GB and peaked at about 1.69 GiB. Search speed is reported 2.9x to 4.6x faster than mctx (JAX, CPU) at batch sizes of 64 and above. Every number is a single run with one seed, from the author; Connect4 also trains end to end, chess and Go are only planned. Built by: natsu0529 · Artefacts: code (MIT) · Signal: Show HN, 4 points, 0 stars at capture. Source: https://github.com/natsu0529/mac-alpha-zero

- layerpool pools laptops, desktops and free notebook GPUs to fine-tune a model none of them could hold — a Python package that splits a model's repeated layer blocks across devices in order, passes activations forward and gradients back, and lets the Hugging Face Trainer run unchanged after swapping the model loader. The author reports QLoRA on Qwen3-8B (4-bit) across a MacBook, a cloud T4 and a two-T4 Kaggle notebook, over internet tunnels, at about 75 tokens/s (sequence length 256, batch 8); with fp32 transfer the loss is said to match a single-machine run, with the default 16-bit transfer changing it by "a fraction of a percent". The catch is that network transfer sets the pace, so it is slower than one large GPU; on a LAN traffic is unencrypted and each device runs part of your model; the README warns Colab and Kaggle may suspend accounts for this use. Built by: abdallah-swe · Artefacts: code (MIT, on PyPI) · Signal: Show HN, 4 points, 15 stars; five commits, so early. Source: https://github.com/abdallah-swe/layerpool

- Harny is a VS Code and VSCodium coding agent whose design goal is making small local models usable — the extension lets you pick any OpenAI-compatible endpoint (Ollama, LM Studio, llama.cpp, MLX) or a cloud provider. Its trick is a loop guard: when a small model repeats its reasoning, its tool calls or its answer, the stream is cut and a "nudge" redirects it (four presets, twelve parameters), identical failing tool calls are refused with the earlier result returned, new sessions start in a dry-run "Analyze" mode that shows diffs without writing, and old turns are summarised at 80% of usable context. The vendor-reported figures (13 tools, 8 providers, about 3,000 unit tests, and one billing comparison where usage fell from a forecast 116% to 94% of a monthly limit thanks to compaction) are the builder's own and not independently measured. Built by: SPLTEK · Artefacts: code (MIT, spltek/harny), marketplace extension · Signal: Show HN, 4 points. Source: https://harny.dev/

- A tool for sending data-broker deletion requests runs as one dependency-free Python file or as an MCP server — fck_data_brokers.py pulls a list of more than 600 registered brokers from public California, Oregon and Texas registries, drafts deletion and opt-out letters citing the law where you live (CCPA, PIPEDA, GDPR), tracks replies and chases silence. On 161 held-out queries from sites not seen in training, top-1 accuracy rises from 82.6% (base) to 89.4% (shipped), top-3 from 93.8% to 96.3%. ## Agents and automation

- Horus runs Claude Code, Codex or OpenCode in an Alpine Linux workspace on an old Android phone, with no root and no Termux — the app builds PRoot in its Gradle build, keeps sessions alive in a foreground service with the screen off, and notifies you when an agent needs input; each agent runs as its own guest user. The README is plain about limits: PRoot gives no kernel isolation, Android's app sandbox is the only boundary, Codex's own Linux sandbox does not work under PRoot so it is launched with `--sandbox danger-full-access`, and the "budget phone from 2021" demo has no benchmarks. Built by: Scarif Labs · Artefacts: code (MIT; components keep GPL/LGPL), F-Droid and GitHub Releases · Signal: 158 stars, 40 forks; Show HN 5 points. Source: https://github.com/scarif-labs/horus

- agent-sim lets agents drive an iOS simulator on ordinary x86-64 Linux, no Mac needed — built on x86Sim (by designgears), which runs Apple's arm64 simulator runtime via Darling, dynarmic ARM translation and Mesa Vulkan rendering Metal through metal2vulkan; agent-sim adds a pre-configured phone, accessibility-tree screen reading as text, .ipa conversion, a phone pool, a browser stream, a CLI and an MCP server. It is self-described as early: XCUITest suites are unsupported, real-device behaviour (camera, push, signing, DRM, performance) cannot be checked, setup takes about half an hour and needs 8+ CPUs, 16 GB RAM and 60 GB disk, and Apple's runtimes must be downloaded by you. Built by: Developing-Gamer · Artefacts: code (Apache-2.0), v0.1.0 · Signal: 616 stars, 63 forks. Source: https://github.com/Developing-Gamer/agent-sim

- Dev-Mem gives coding agents a local, typed memory graph in SQLite — hooks log tool calls with no LLM cost and redact secrets, then one batched LLM call per session extracts nodes (Decision, FailedApproach, Constraint, Discovery, OpenIssue) with evidence pointers and lifecycle states (observed, active, verified, superseded, stale); retrieval scores by topic similarity, freshness, confidence and file proximity within a token budget, and verified nodes export to a Git-committable file and an MCP server. Extraction needs an LLM key (Anthropic, OpenAI, Gemini, or local Ollama). Cursor and OpenCode lack a reliable session-end flush, corrupted state is not repaired, and there is no evidence of use beyond the author. Built by: HarsH-1877 · Artefacts: code (MIT, npm dev-memo) · Signal: Show HN, 7 points, 4 stars. Source: https://github.com/HarsH-1877/Dev-Mem

- agentdream consolidates an agent's memory notes against its recent session transcripts, offline-style — it loads the memory read-only, redacts secrets, merges near-duplicates, replaces stale values, resolves reversed preferences while keeping a one-line history, corrects notes the transcripts contradict with file:line citations, and surfaces recurring patterns, writing a separate store plus report so you accept or reject each change by ID. It positions itself as an open-source take on Anthropic's Dreams and the sleep-time compute paper (arXiv:2504.13171) and says it is unaffiliated with them. There are no benchmarks, only a demo run on bundled sample data (one correction, one replacement, one merge, three insights). Built by: mvplab-ai organisation (copyright notice names systemagents-ai) · Artefacts: code (MIT) · Signal: 2 stars. Source: https://github.com/mvplab-ai/agentdream

- Weaponized Curiosity is a portable skill that makes Claude Code or Codex research before committing, with four modes — Quick (check a claim), Deep (up to four independent workers), Extreme (more sources and replication) and Autoresearch (optimise a measurable target against a fixed evaluator). It starts with the evidence most likely to change the answer, for close calls reports what would flip the recommendation and the cheapest test, and for optimisation runs works in an isolated copy with a reserved validation batch, saving state under .research/<run-id>/. The one worked example (indexing all values was about 41x faster on fresh inputs but broke a memory cap; a narrower candidate passed) and the "tested on architecture decisions" claim are the author's own and a small sample. ## Experiments, demos and write-ups

- "AI made self-hosting fun again" and the 205-comment argument about it — Jan-Lukas Else describes keeping Docker Compose files and scripts in Git so coding agents can work on them, moving to NixOS, building a Debian bootc VPS image in about half a day with AI (he estimates at least a week without), using Renovate plus Actions for updates he can merge from his phone, and writing small Go tools. He names no models and gives no AI costs, and lists the costs himself: every added service is maintenance, AI-written code carries bugs and debt, and he stays responsible for what the agent changes. The HN thread (372 points) is the useful part: practitioners run about 60 services through Claude Code, agents confined to Makefiles or playbooks rather than raw SSH, security patching still falls on the human, and critics say codified Ansible is cheaper and more reliable than repeated agent runs and that this swaps config drift for subscription dependence. Built by: Jan-Lukas Else · Artefacts: write-up · Signal: 366+ HN points, 205 comments. Source: https://janlukas.blog/posts/ai-self-hosting (thread: https://news.ycombinator.com/item?id=50660180)

- open-interpretability explain traces how a small model picked its next token, with agents proposing and attacking the explanation — for pythia-70m on "The sun rises in the" it ranks neurons and heads by deviation from a roughly 20,000-token baseline times sensitivity of the " sky" score, ablates and prunes to a core circuit, then has a proposer agent write a claim that a reviewer agent (without the measurements) tries to break with new prompts. Reported results: the explained units account for 10.1% of the direct push on " sky" yet the route they form removes about 80% of its probability when ablated; 86 units restore 81.9% (random sets restore 13%); pruned to 21 units they still restore 75.7%; patching the route from a corrupted prompt moves the answer 86% of the way versus 8.3% for random units. All of this is one 70M-parameter model and a handful of prompts, by the project's own account; the hallucination example ("a year has twelve" completed as " days") is explained as pattern copying. Built by: Open Interpretability project (repo 8W9aG/openinterpretability, v0.6.0) · Artefacts: write-up with experiment JSON and figure script, code (licence not stated) · Signal: Show HN, 11 points. Source: https://open-interpretability.com/posts/explain/index.html

- Silent dictation for Claude Code by on-device lip reading — a prototype plugin where you mouth a prompt at the webcam and Auto-AVSR's visual-only model (250M parameters, trained on 3,291 hours of video) types it into the prompt box, with MediaPipe cropping the mouth, beam search, and optional personal LoRA adapters (about 2M parameters). Everything runs on the Mac's GPU with no audio and no video leaving the machine after a roughly 1.5 GB one-time download. The README concedes that the quoted accuracy (about 80% word accuracy, 20.3% word error rate on the LRS3 TED benchmark while speaking aloud) is not what silent mouthing on a laptop webcam gives, which "varies by person" with no figure; the pretrained weights have no explicit licence and the training data is research-only. Apple Silicon and a recent Claude Code only. Built by: batanus · Artefacts: code (MIT) · Signal: Show HN, 15 points, 10 stars. Source: https://github.com/batanus/lip-dictation
