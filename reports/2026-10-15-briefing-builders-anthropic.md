## Local models and agents

- Babytalk: offline speech-to-text and text-to-speech on a $20 ESP32 — Thomas Lackner (with Claude Opus 5.5) wrote int4 kernels for the ESP32-S3/P4 and squeezed NVIDIA's Citrinet-256 speech recogniser into 6 MB of flash and 84.5 KB of internal RAM (the model is read in place from flash), plus a 1.9 MB neural voice. It transcribes arbitrary English sentences with no cloud and no fixed command list, from C, MicroPython or AtomVM (Elixir/Erlang); a fine-tuned noise-robust variant is included. Interesting for LoRa radios and screenless devices. Accuracy and speed figures (about 0.5 s for 2 s of speech on the S3) are the author's own; English only. Built by: Thomas Lackner · Artefacts: code (MIT; models carry their authors' licences) · Signal: 14 HN points Source: https://github.com/tlack/babytalk
- Pulse Local: a Mac budgeting app whose chat assistant runs on-device — Niz's beta (Apple Silicon) imports bank CSVs in any currency and answers questions about spending from a fine-tuned local model plus thousands of hand-coded rules; a second 2.5 GB model verifies every money answer on machines with more than 16 GB of memory. The app lists exactly what leaves the machine (model download once, update check) and sends no analytics. Closed app, free in beta, so the privacy claims cannot be inspected in code; a commenter noted the domain is under 30 days old. Built by: Niz (solo) · Artefacts: demo / downloadable app, no source · Signal: 114 HN points Source: https://news.ycombinator.com/item?id=50080275

## Open-source projects and tools

- Graphicle: a Rust port of Graphify with memory for coding agents — one Rust binary builds a tree-sitter code graph of a repository (no model needed), stores docs, decisions and past agent sessions in one SQLite file, and serves cited excerpts to Claude Code, Cursor, Codex or any MCP client; no API key or telemetry. The authors claim a 31k-file Kubernetes extract in 3 min 18 s versus 26 min 38 s for Graphify (one exploratory run each) and a pre-registered memory comparison against seven systems. HN commenters questioned whether such memory layers beat plain ripgrep in agent evals. Built by: graphicle-ai (KarLexAI on HN) · Artefacts: code (Apache-2.0), Linux/macOS releases · Signal: 42 HN points Source: https://github.com/graphicle-ai/graphicle
