## Safety and security

- 🚨 Critical NGINX bugs, found with AI help, let attackers run code on HTTP/2 servers — F5 shipped out-of-band patches for 10 CVEs in open-source NGINX on 18 November. Two are unauthenticated remote code execution flaws rated 9.2 on CVSS 4.0, and both need HTTP/2 enabled. One reaches back to NGINX 1.9.5 (2015). Five groups (Wiz Research, Ikotas Labs, Metnir, Rapid7, Xint) found them independently, most with AI assistance. F5 says it has seen no exploitation in the wild, and the fixed release is 1.31.9. NGINX serves roughly a third of websites (about 225 million), and The Register ties this to a run of AI-found flaws in PHP, Apache and Java. That is the point for readers: AI-assisted discovery now finds decade-old bugs in foundational software faster than maintainers and operators can patch. Wiz's timeline shows its second report reached F5 on 16 November and was confirmed on 17 November, so disclosure cycles are now measured in days. Source: https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities (press account: https://www.theregister.com/security/2026/11/18/ai-found-more-critical-bugs-in-another-widely-used-technology-running-225m-websites/5310887)

- Microsoft's official Python agent framework hijacked on PyPI to steal developer credentials — The Register reports that versions 1.26.1 and 1.26.2 of Microsoft's `agent-framework` package (about 200,000 downloads a month, used to build AI agents) carried an information stealer. - "Java4Shell": AI-found flaw in OpenJDK's Base64 decoder, patched in Oracle's November update — Oracle fixed a memory-corruption bug in a vectorised code path of the Java standard library. It affects OpenJDK 17.0.6 and later on x86-64 CPUs with AVX-512 VBMI. Malformed input can crash the JVM or give unauthenticated remote code execution, and because it sits in the standard library, many third-party applications inherit it. Calif.io found it with AI flaw-finding tools it says cost about $200 in tokens, and rated it 9.2 (CVSS 4.0). CISA issued an alert on 17 November urging immediate patching. The stated mitigation is to start the JVM with AVX-512 support disabled. A single researcher's token bill of about $200 sets the price of finding a critical library bug. Source: https://www.theregister.com/security/2026/11/18/oracle-reveals-fix-this-asap-grade-java4shell-bug-that-allows-attacks-on-many-third-party-apps/5310661

- UK parliamentary committee calls for a regulator that can halt dangerous AI models — the Business, Innovation, Science and Trade Committee's report "Guardrails for Growth: Making AI Safe" wants an AI Safety and Security Bill. A new enforcement regulator could halt high-risk training and testing, block deployment or suspend services. The report lists ten gaps, including no mandatory incident reporting, limited independent tester access and weak whistleblower protection. The AI Security Institute would keep testing but has no power to stop a release. OpenAI, Google DeepMind, Anthropic and Meta told MPs they would not release unsafe models, but they use different yardsticks. Chair Liam Byrne warned against "unfettered freedom". Tension: voluntary company assurances against a demand for statutory, pre-release powers.
