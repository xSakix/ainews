- Microsoft releases Mage-VL-Cowork, a 4B open model that handles both screen clicking and terminal commands, and reports 66.0% on OSWorld-Verified — The model card (Apache-2.0, created 30 October) describes one vision-language policy that chooses per turn between a GUI tool (11 primitives) and a persistent bash/Python shell, built on a 4B Mage-VL checkpoint with a Qwen3-4B language backbone. Microsoft's own numbers: 66.0% on OSWorld-Verified (361 tasks, 50-step budget, two-run average), best among 4B models by its own comparison; online RL added 10.16 points over supervised fine-tuning while cutting output tokens per task by 25.4%. Its synthesis pipeline is said to cut data-generation cost from $0.906 to $0.158 per task. All figures are the authors', not independently reproduced; a technical report PDF and code sit in the microsoft/Mage GitHub repository linked from the card. For a reader following local and on-device agents, a 4B computer-use model with open weights is the notable part. Artefacts: weights (Apache-2.0) / technical report / code · Sizes or variants: 4.74B parameters in BF16, 32,768-token active context (architecture supports 262,144); sibling checkpoints Mage-VL and Mage-ViT · Released: 30 October 2026. Source: https://huggingface.co/microsoft/Mage-VL-Cowork

- NVIDIA publishes an official NVFP4 4-bit checkpoint of DeepSeek-V4.1-Flash-1017 for Blackwell GPUs — The model card says it is a quantisation of DeepSeek's open model (552B backbone, 8B active during prefill and 16B during decode, plus a 196B "Engram" memory, context up to 1M tokens), produced with TensorRT Model Optimizer 0.48.0rc0 and calibrated on 1,024 samples. It cannot run on stock vLLM: the Engram tables are stored as MXFP4 and need a vLLM build that includes pull request 61530; SGLang is not validated. Useful as a sign that a Chinese open model is being tuned for US hardware by the hardware vendor; a quantisation, not a new model. Artefacts: weights (MIT, inherited from DeepSeek) · Sizes or variants: single NVFP4 checkpoint (about 665 GB of safetensors), Blackwell only · Released: 30 October 2026. Source: https://huggingface.co/nvidia/DeepSeek-V4.1-Flash-1017-NVFP4

## 2. Europe

- JetBrains adds a multi-token-prediction head to Mellum2.1 Thinking, its open 12B coding model, for faster decoding — The new repository holds the same weights as the 20 September release (the card says they are byte-identical) plus one extra shard that serves as a draft head for speculative decoding with vLLM 0.33 or later and transformers 5.20 or later. The base model is a 12B mixture of experts with 2.5B active parameters and a 131,072-token context, trained mostly by reinforcement learning in real repositories with a shell, rewarded when tests pass. What is new is only the speculative-decoding head; no speed-up figure is given on the card. Artefacts: weights (Apache-2.0) · Sizes or variants: 12.1B total / 2.5B active, MTP variant of Thinking · Released: 30 October 2026 (base model 20 September). Source: https://huggingface.co/JetBrains/Mellum2.1-12B-A2.5B-Thinking-MTP

Relevant to anyone choosing between agent platforms: computer use is now a supported product on three major vendors' APIs.
