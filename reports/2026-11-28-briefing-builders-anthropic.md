## Local models and agents

- Inkling 2 Mini at 101 tok/s in vLLM on one GB10 box — "Anand" (runtimenotes.com) tuned vLLM for Thinking Machines' Inkling 2 Mini (131k context, 8 of 128 experts per token) on an MSI EdgeXpert, the DGX Spark variant with one GB10 and 128 GB shared memory. Five changes: a compile-stall fix (stalls down 67–90%), INT8 draft copies, probabilistic drafting (+14–20% on sampled requests), adaptive verify width (about +5%) and retuned prefill tiles (32K time to first token 12.2 s to 9.7 s). Result: 101.0 tok/s single-request and 195.7 tok/s aggregate over four, against the author's own DFlash2 baseline of 90.3 and 163.8 (published setups: 61.4 and 88.2 single-request). Caveats: whole setups are compared (36% GPU memory and FP8 KV cache here against 80% and BF16 in the rival), prefill is still behind SGLang (about 3,400 against 5,085 tok/s), and some gains depend on tuned thresholds. The HN thread (44 points) disputes model quality: some call it weaker than same-size peers and report tool loops, others like its style, and people report about 150 tok/s on a Mac (oMLX) and about 220 tok/s on an RTX 5090. Built by: Anand · Artefacts: write-up with config (no repo checked) · Signal: 44 HN points, 11 comments. Source: https://runtimenotes.com/blog/getting-101-tok-s-from-inkling-2-mini-in-vllm-on-one-gb10/ (thread: https://news.ycombinator.com/item?id=50670443)

- LLM.OS: Qwen3.5-2B in a browser tab on a 52 KB WebAssembly engine — Tesseracted Labs GmbH ported the assembly-language llm.asm approach to a Zig WebAssembly engine that runs Q4_K_M GGUF weights (about 5.3 bits per weight) on the CPU, with no prompt leaving the tab. Measured on an M3 Max with 8 threads: about 39 tok/s for Qwen3.5-2B and about 124 tok/s for Qwen3-0.6B, roughly 65–75% of native llama.cpp generation speed, but prompt processing lags (about 160 against 513 tok/s for the 0.6B). 4-bit keeps the same top token as full precision 90.6% of the time for Qwen3-0.6B (98.5% at 8-bit). A `/python` command runs model-written code in a network-free CPython sandbox (standard library only, 15 s limit); the tab uses about 1.4 GB. Small-model errors remain; the numbers are the builders' own. Built by: Tesseracted Labs GmbH · Artefacts: demo plus write-up (code not confirmed) · Signal: 3 HN points. Source: https://tesseracted.com/experiments-llm-os/ (thread: https://news.ycombinator.com/item?id=50673018)

- ippon: a local runtime for "decision models" on Apple silicon — Sqwish Labs' Apache-2.0 runtime (MLX/Metal, CLI, Python `Decider`, HTTP server, MCP tools) returns probabilities for yes/no and multiple-choice questions over text, image, audio or video instead of generating text. Self-reported on an M5 Pro with 48 GB: 51 ms text (14 ms with cached context), 39 ms audio, 179 ms image, 828 ms video. It claims on average 34% faster than Ollama, 3.4x faster than llama.cpp and 45% less memory than Ollama, but its own tables show llama.cpp with lower median latency at 16 concurrent clients. The project's own Kettei models (3.7B and 0.9B) use a community licence; some listed models are non-commercial. The numbers have not been verified independently. Built by: Sqwish Labs · Artefacts: code (Apache-2.0; model licences vary) · Signal: 59 GitHub stars. Source: https://github.com/sqwishai/ippon

- Prospero: a native C++ coding-agent harness with Dear ImGui — Chris Wellons (skeeto), per the repo owner and the HN thread, built a single-executable GUI harness for Windows, macOS and Linux that can run headless or over SSH and idles at no cost. It speaks the OpenAI Chat Completions API (llama.cpp, vLLM, LiteLLM) and Anthropic's Messages API with extended thinking and prompt caching, and ships no default provider; a built-in network, `src/gemma.cpp`, derives from gemma4.c. Unlicense, with SDL3, Mbed TLS and others bundled. An HN commenter notes a roughly 5 MB Windows binary. A counter-view to Electron-based harnesses; no benchmarks are claimed. Built by: skeeto · Artefacts: code (Unlicense) · Signal: 240 stars, 37 HN points. Source: https://github.com/skeeto/prospero (thread: https://news.ycombinator.com/item?id=50671275)

## Open-source projects and tools

- Tabernetes: a Kubernetes cluster whose nodes are browser tabs — Farid Zakaria's 0.1.0 lets a visitor's tab join a cluster as a node. A Linux kernel compiled to WebAssembly runs pods marked `runtimeClassName: tab` through a container runtime called tabc, and closing the tab triggers rescheduling. Joining costs about 5 MB, the guest has one core and lives only while the tab is open; demos are an awk Mandelbrot over 64 tiles and a Redis visit counter. Interesting as plumbing for untrusted volunteer compute, with no performance figures claimed. Built by: Farid Zakaria · Artefacts: code (MIT) / live demo · Signal: 43 HN points. Source: https://tabernet.es/ (code: https://github.com/fzakaria/tabernetes)

- Three Linux VMs, each running a different browser, in one tab — michidk's "sidebyside" builds on the trynix and unkernel projects (the author confirmed this), with guest TCP carried over a WebSocket to a public Wisp relay. There is no GPU, so rendering is software. Commenters report connection failures and a vsock error, question the sandboxing story of a browser inside WASM inside a browser, and ask how public relays avoid abuse. Related to Tabernetes above through the tabc runtime a commenter linked. Built by: michidk · Artefacts: live demo (repo not confirmed) · Signal: 153 HN points. Source: https://michidk.github.io/sidebyside/ (thread: https://news.ycombinator.com/item?id=50656036)

- Ghost Mode: Rust "code mode" for agent tool calls — the model writes a short Python script that chains tool calls inside your process (Monty backend), seeing only `execute` and `poll`; optional MCP support and a worker pool for untrusted scripts. The HN title claims about 60% fewer tokens, but the repo makes no such claim and cites others' results (Anthropic's 150,000 to 2,000 tokens in one workflow, a benchmark with a 40.7% average cost cut), noting that weaker models sometimes cost more. Treat the figure as unmeasured. Built by: legend-of-alan · Artefacts: code (MIT) · Signal: 11 stars, 3 HN points. Source: https://github.com/legend-of-alan/ghostmode (thread: https://news.ycombinator.com/item?id=50665796)

- SessionGraph: one graph of all your coding-agent sessions — reads session stores from more than 50 harnesses (Claude Code, Codex, Cursor, Gemini CLI), indexes them locally, and offers a desktop app, MCP search and a REST API via `npx sessiongraph`. It says everything stays local; the page states no licence and names no stack. Built by: GitHub account arvindell · Artefacts: code (licence not stated) / desktop app · Signal: 33 HN points. Source: https://sessiongraph.ai/ (code: https://github.com/arvindell/sessiongraph)

- 7paws: a 3D desktop cat that an AI can redesign over MCP — a Tauri 2/Rust and three.js pet for Windows and macOS that reacts to global keys and mouse, with a built-in stdio MCP server (`upsert_cat`, `switch_cat` and others) so an AI client can generate coat colours and patterns, which show up in about a second; photos go only to the client you choose. MIT, no telemetry; a small example of MCP as a product's customisation surface, not only a developer tool. Built by: GitHub account 7wdn · Artefacts: code (MIT) · Signal: 158 stars. Source: https://github.com/7wdn/7paws

## Agents and automation

- OneBrain Rooms: coding agents in one group chat with a Markdown brain — a Mac app (Rust/Axum/SQLite backend, React, Tauri) where Claude Code, Codex and Gemini CLI share a room; each agent reads only messages it has not seen, which the author's own benchmark says cuts input tokens by 31–81%. Shared memory is a git-tracked Markdown folder following the AGENTS.md convention, with agent-authored commits, per-run file undo and approval cards for risky commands. It reuses your existing CLI subscriptions and credits brainmaxxing for the memory idea. Built by: 0xTaoZ · Artefacts: code (Apache-2.0) · Signal: 34 stars. Source: https://github.com/0xTaoZ/onebrain

- agent-phone: an iPhone automation CLI for agents — reads the iOS Simulator accessibility tree through short element refs, with no screenshots, Python or WebDriverAgent, and drives input through SimulatorKit's HID client. For a real phone it uses macOS iPhone Mirroring, where accessibility is unavailable, so it reads the screen with Apple's Vision OCR and sends CoreGraphics events; the Mirroring window must stay in front. Only 11 commits and no releases yet; no success rates published. Built by: govijr · Artefacts: code (MIT) · Signal: 49 stars. Source: https://github.com/govijr/agent-phone

- Sentinel: a supervisor that audits coding agents for sabotage — from the run-llama organisation, it polls terminals running claude, codex, aider or gemini on macOS, collects `git status`, `git diff HEAD` and recent commits, and has an auditor model (default Gemini 4 Hydrogen, or OpenRouter or Ollama) judge whether the diff matches what the agent claims. Verdicts include `sabotaging_work` (weakened tests, deleted files, bypassed checks), `potential_mistake` and `taking_bad_initiative`. Early: 6 commits, no accuracy figures, and it relies on a model to judge a model. Built by: run-llama (individuals not named) · Artefacts: code (Apache-2.0) · Signal: 3 stars, 1 HN point. Source: https://github.com/run-llama/sentinel

- Shandu 4.0: a local deep-research agent that audits its citations — a `CitationAuditor` rechecks each cited sentence, bullet and table row against extracted page text and verified quotes, and strips markers the source does not support; a `CitationAgent` drops low-credibility pages before writing. Works with any LiteLLM model (default `deepseek/deepseek-flash`), with separate models per role. The repo shows no changelog or release date for 4.0 and no measured citation-error rate; the claim is the author's. Built by: jolovicdev · Artefacts: code (MIT) · Signal: 16 stars. Source: https://github.com/jolovicdev/shandu

- Carry: saves web chats from ChatGPT, Claude, Gemini and Grok as Markdown — a browser extension that writes conversations to a folder you choose and hands a saved chat to another assistant; an MCP server and CLI are promised. Closed source with a one-time payment (Polar), and the author says some usage events are sent by default and can be disabled, so the "never uploaded" privacy claim cannot be inspected; commenters also noted AI-generated site copy and that agent runs outside the browser are not covered. Built by: HN user iankit17 · Artefacts: closed-source extension · Signal: 31 HN points. Source: https://carry.md/ (thread: https://news.ycombinator.com/item?id=50637995)
