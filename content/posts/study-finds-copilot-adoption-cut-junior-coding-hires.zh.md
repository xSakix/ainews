2023年秋，一家大型保险公司的平台工程总监正在参加 GitHub 合同续约会议。会议多年前就已排定，每年一次，法务、安全和财务负责人都已上线。客户经理在订单上新增了一行：编程助手 Copilot。用不着另行申请采购，不必排队等安全审查，也不用再找预算科目。总监看了眼未来四个季度的招聘计划，上面还列着七个应届生岗位。她让财务负责人批准了这笔采购。

*本文开头和结尾的场景为示意性描写，其中人物均为虚构。*

这样的招聘计划后来怎么样了？2026年11月23日发布在 arXiv 上的一篇预印本研究了这个问题。麻省理工学院（MIT）的 Lindsey Raymond 和微软研究院（Microsoft Research）的 Eleanor Dillon 追踪了 5,414 家大型企业。这些企业共雇用 4,500 万人，美国 38% 的程序员在其中任职。作者报告称，对于因合同续审而决定采用 Copilot 的企业，每季度新招的技术人员减少了 29%，初级软件工程师的招聘量下降约 40%。论文尚未经过同行评审。作者表示，文中观点仅代表个人，不代表各自的雇主。

## 为什么续约会议能成为自然实验

较早引入编程助手的企业与较晚引入的企业本来就不同。在这批样本中，早期采用者在 Copilot 推出前就招人更多，企业规模更大，更偏重技术，员工年龄也更高。如果只比较采用和未采用的企业，工具的效果就会和企业本身的特点混在一起。

作者借助续约会议区分两者。所有样本企业原本都购买了 GitHub 企业产品，并按固定周期与销售人员会面。日程在 Copilot 出现前就已确定。产品推出前，在续审前后两个月里，增加许可证数量的企业占比会从约 10% 升至约 40%，可见采购高度集中在会议前后。Copilot 企业版于 2023年1月推出后，续审日期越早的企业，越有可能较早采用这款工具。续审一年后，这些企业采用 Copilot 的概率，比尚未轮到续审的企业高出 20 个百分点。

作者接着比较已续审与尚未续审企业的招聘情况。产品推出前，续审并不影响技术岗招聘；推出后，续审也没有影响会计等非技术专业岗位的招聘。这两项检验回应了一种疑虑：会议可能恰好赶上预算周期或招聘冻结期。研究使用了 Revelio Labs 根据公开职业档案和招聘广告整理的就业履历，以及 GitHub 自己记录的企业采用情况和时间。

## 采用 Copilot 的企业发生了哪些变化

到了续审日期的企业，每月新招的技术人员比尚未续审的企业少 7.6%。将这一差异折算到因续审而采用工具的企业，作者估计其季度技术岗招聘量下降了 29%。以每家企业每季度约招 55 名技术人员为基准，降后约为 39 名。样本企业平均有 8,284 名员工，因此每季度的变化不到员工总数的 0.2%。

没有人因此遭到解雇。第一年内，离职人数和技术人员总数均未变化。公开招聘的技术职位减少了 14%，但广告持续开放的时间没有变化。作者据此判断，企业开出的职位变少了，填补空缺并未变得更难。

降幅并不均匀。作者利用 2023年以前的岗位说明，为各类岗位的编程工作占比打分。初级岗位的招聘降幅集中在编程最多的岗位。另一端则没有可见影响：资深软件工程师以及系统和基础设施工程师的招聘量都没有变化。Copilot 出现前，新入职的初级技术人员有 72% 进入编程密集型岗位。作者估计，采用工具后这一比例降至 52%。资深人员的招聘总量没变，人员构成却变了。新招的资深软件工程师潜在工作年限多了约 1.3 年，持有硕士或博士学位的概率高出 4.7 个百分点。这些岗位的外部招聘减少约 13%，内部补岗数量保持稳定。作者还检查了工作是否转移至主要离岸业务中心印度，没有发现这种迹象。若说有何不同，印度的招聘放缓幅度反而更大。

这一结果与作者引用的一项实验发现形成反差：在单项任务中，新手从 AI 辅助获得的收益最大。个人从工具中受益更多，并没有转化为企业对相应岗位的更大需求。

## 招聘放缓有多少可归因于 Copilot

在样本企业接触 Copilot 之前，技术岗招聘已经开始减少。从 2022年到 2024年，企业平均每季度新招的技术人员从 55.3 人降至 39.2 人，降幅为 29%。这一数字与采用工具的估计效应恰好相同，但两者衡量的不是一件事。在从未采用 Copilot 的企业中，同一三年间的月度招聘率也从 2.7% 降至 1.8%。

作者将部分降幅归因于这款工具，并根据不同假设给出三种估计。如果续审时观察到的效应适用于每一家企业，Copilot 可解释总降幅的 10%。如果它只适用于与因续审而采用工具的企业相似的公司，则可解释 19%。如果所有采用者都像受续审推动的企业一样反应，则可解释 51%；截至 2024年，采用者约占样本的一半。作者称，这些估算仅作说明。研究设计无法分辨剩余降幅来自哪些因素。她们列举了货币政策收紧、疫情期间过度招聘后的调整，以及软件研发税务处理方式的变化。

她们还提醒读者留意其他研究的局限。比较受 AI 影响程度不同的职业时，也会捕捉到技术工作整体下行的趋势。作者估计，这一趋势至少可以解释 2022年后招聘降幅的一半。

## 研究能说明什么

估算针对的是单个企业，并不涵盖整个劳动力市场。没有被保险公司录用的人，可能会进入规模较小的公司。一家企业以竞争对手的损失为代价扩张，也可能让观察到的结果显得更好。研究观察的是每次续审后的第一年，时间覆盖 2023年至 2025年年中。当时 Copilot 是企业市场的主流助手，Cursor 和 Claude Code 的企业版还未出现。样本企业规模大、成立时间长，大多位于美国或欧洲。29% 的降幅只针对因续审而采用 Copilot 的企业，不能直接套用到每个采用者身上。

这项工作延续了近几周的一条研究线索。Borri、Cheremukhin、Liu 和 Tsyvinski 在 11月20日的预印本中发现，企业受智能体使用的影响程度与非资深职位广告减少有关，衡量的是广告而非实际入职人数。斯坦福大学（Stanford University）一项基于 ADP 工资数据的研究于 8月12日修订。研究发现，在受 AI 影响的岗位上，22 至 25 岁人群的就业水平比趋势值低 19%，较年长员工则没有类似差距。Indeed 在 11月24日的招聘快报中将软件开发岗位指数列为 82，2020年2月的基准值为 100。这些来源使用招聘广告、工资记录和关键词计数。本研究还掌握了企业采用工具的记录，并能解释采用时间为何不同，因此可以讨论因果关系。

一年后，保险公司的平台工程总监再次打开那份计划。七个应届生岗位还剩三个。取而代之的是一个要求五年经验的职位，最终入职者拥有硕士学位。
