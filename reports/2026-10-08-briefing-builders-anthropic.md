## Local models and agents

- nanoMuse, a self-hostable personal agent for phone and desktop — A GPL-3.0 monorepo containing an Android app (Alpine Linux under proot with a shell, browser and MCP), a desktop app, a web console and a relay that links them. A task said on the phone can run on the PC; it supports 18 model providers or plans you already pay for, keeps agent memory as editable Markdown files, and asks before deleting, sending or paying. The repository's own news list gives the first release as 25 September; what is new in the window is v0.1.41 (7 October) and an arXiv paper the authors say they posted that day (not checked). Commenters on HN asked about security boundaries. Capability claims are the builder's own. Source: https://github.com/nano-muse/nanoMuse

- rGPU, a PyTorch device whose tensors live on a remote NVIDIA GPU — The application stays on the client while GPU work runs on a remote machine over TCP/SSH. There is a simple `device="rgpu"` path for PyTorch programs, and a CUDA shim (libcuda, CUDA Runtime, cuBLAS, cuBLASLt, cuDNN) meant to run existing Linux CUDA binaries, including stock CUDA PyTorch. Docs include a nanoGPT training example and a performance page. Useful for people with a laptop and a GPU box elsewhere on the network. Compatibility and speed claims are the builder's own. Built by: ymcrcat · Artefacts: code (Apache-2.0), docs site · Signal: 8 HN points. Source: https://github.com/ymcrcat/rgpu

## Open-source projects and tools

- Terse, a Claude Code plugin that cuts reply length and mannered prose — Writing rules for replies, documents, commits and subagents, plus a status-line context meter. The author reports, on 20 prompts against a real codebase, 46% fewer words and 51% lower cost on Fable 5.1, and 54% fewer words and 32% lower cost on Opus 5.5, scored by an Opus 5 judge counting style violations. Interesting as a worked example of making style instructions persist across turns, where plain system prompts were forgotten. Benchmark is self-run. Built by: lowenbjer (individual) · Artefacts: code (MIT), benchmark write-up in repo · Signal: 13 HN points. Source: https://github.com/lowenbjer/claude-terse

## Agents and automation

- A SimCity 2000 clone ported by Opus 5.5 from the original PowerPC code — Per the author, a single prompt had the model decompile the Mac original with Ghidra and translate it function by function, using 27 subagents to reach a running WebGL/TypeScript version in about 2 hours. A follow-up had it build a harness around a PowerPC emulator (Unicorn) with faked Mac system calls, and compare game state over 10,000 simulated days. 3D and vector assets are code-generated, bitmaps come from GPT Image 2. HN commenters raised clean-room and legal concerns about feeding the original code to the agents that wrote the new code. The author's account of the process and the fidelity claim are unverified. Built by: an individual (dator.dev) · Artefacts: playable demo, no repository found · Signal: 35 HN points, 8 comments. Source: https://dator.dev/city2026/
