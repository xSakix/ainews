## 4. Rest of the world

- Sarvam AI releases Sarvam Prism, an open-weight "decision model" built on Sarvam 105B — Prism takes a context and questions that each have a fixed set of possible answers and returns a probability for every answer in one forward pass; it does not generate text, so output is always one of the options. Sarvam's own tests of 25 decision models on three indices give it an average of 71.8 at a 44 ms median response on one B200, which it says is the highest score under 100 ms; two models score higher on average (mammoth-1 at 75.2 and GLiDE 1.2 at 73.2) but are slower (284 ms and 116 ms). It scores 82.5 on an Indian-languages index and the post claims order-of-options invariance and confidence that bounds its errors. Sarvam benchmarked the competitors itself and times only models it could run. The model is on Hugging Face under Apache-2.0 for English plus ten Indian languages; it needs about 120 GB of GPU memory with FP8 support, and a hosted API exists. Why it matters: it is a concrete non-US entry in a model category (fast classifiers that replace long generated reasoning for routine enterprise decisions) that only appeared last month. Artefacts: weights (Apache-2.0), code, release blog, hosted API · Sizes or variants: built on the Sarvam 105B-10B mixture-of-experts base (about 106 GB of weights) · Released: 3 November 2026 (blog); Hugging Face repository created 2 November.
