- Underdog releases Woof, a 40.6 MB English text-to-speech model that runs on a laptop CPU with only numpy — The two-voice model (Juno and Mira) is a single 40.6 MB file and needs 402 MB of memory at peak; a one-voice 31.7 MB variant runs in a browser at underdog.ai/woof. On the card's own test (Gradium "TTS Hard Cases", 500 English sentences, run and scored by the authors with a Qwen speech-to-text model and Gemma counting word errors) Woof gets 1.42% of words wrong against 1.89% for Fish Audio Drama 3 (a 41.5 GB open-weight download) and 2.16% for Phonon 31m; speed is 13.8 times real time on one Apple M5 Max CPU thread. A built-in rule-based normaliser reads phone numbers, dates and prices aloud. The comparison is the lab's own, on one hard-cases set, and the licence is a custom non-commercial one; the card does not say where the lab is based, so its place under this region is a convenience. Why it matters: for anyone building voice features, a speech model small enough to ship inside an app, an offline tool or a browser page changes what a cloud text-to-speech bill is for. Artefacts: weights, runtime code and sample audio (Underdog non-commercial licence 1.0) · Sizes or variants: one voice 31.7 MB, two voices 40.6 MB · Released: 5 November 2026 (repository created 19:07 UTC). Source: https://huggingface.co/ConwayResearch/Underdog-Woof

## China

- Tencent publishes DSpine drafters for Qwen3.8-27B, the first checkpoint for a model people actually run locally — The earlier DSpine release (16 October) was a Qwen3-8B drafter; on 7 November Tencent added a five-layer, 2.0B-parameter draft model for Qwen3.8-27B (block size 16, 8,192-token sliding window), Apache 2.0, for use with SGLang. The new element is the model size people run locally and a comparison with the official DFlash2 drafter (block size 8) on agent replays. Tencent's own measurements, on SGLang 0.5.22 with BF16 at concurrency 8: average accepted draft length of 7.20 against 5.69 on GSM8K, 5.08 against 4.19 on its WorkBuddy Code replay and 4.99 against 4.19 on SWE-bench Pro, and end-to-end speed-ups over plain decoding of 2.7 to 3.8 times at low reasoning effort and 2.9 to 3.5 times at the highest (DFlash2: 2.3 to 3.2 and 2.6 to 3.1). Agent replays use 20 conversations per subset. Why it matters: speculative decoding is the cheapest way to make a local 27B coding agent feel faster, and this one ships weights, code and a launch command. Artefacts: weights (Apache 2.0), code, paper (arXiv 2609.36173, September) · Sizes or variants: one draft model for Qwen3.8-27B, block 16 · Released: 7 November 2026 (repository created 14:20 UTC). Source: https://huggingface.co/tencent/Qwen3.8-27B-DSpine-b16

- Adventists AI publishes the Sophon-Realtime v1 model card, an open full-duplex voice model, but the repository holds no weights yet — The card describes a speech-to-speech model that listens while it talks, decides in a single token at each pause whether you have finished, drafts its reply early and stops when interrupted, with a reply starting about 0.4 seconds after you stop. It claims 82.8 on VoiceBench (equal to GPT-4o-mini-Audio, ahead of the open full-duplex models listed such as MiniCPM-o 4.5 at 76.1), 81.8% on Big Bench Audio against 90% for GPT-Live-1, and 48% Pass@1 on Full-Duplex-Bench v3 tool calling against 60% for GPT-Realtime and 43% for Grok; the Big Bench Audio score is self-run and judged by gpt-4.1, and the tool-calling figure is the best of several runs. It says the code and weights are Apache 2.0, a quantised build fits one consumer GPU, and the server speaks the OpenAI GPT-Live interface format. At the time of checking the Hugging Face repository (created 7 November, 03:06 UTC) contains only the README files and banners, and the GitHub repository did not load from here, so nothing is yet checkable beyond the card. The lab's earlier DuplexJev models (September to October) are in the same organisation. The card is bilingual (English and Chinese) and lists a ModelScope mirror; the lab's location is not stated. Why it matters: if the weights arrive as promised, it would be the first open voice model benchmarked against a realtime API on tool use, which is where voice agents have so far been weakest. Artefacts: model card only so far; weights and code promised (Apache 2.0) · Sizes or variants: not stated (DuplexJev-32B-Para is named as its ears) · Released: 7 November 2026 (card). Source: https://huggingface.co/adventists-ai/Sophon-Realtime-v1

## Rest of the world

- Civimatica releases Blue Marble, tiny satellite-image models for floods, clouds, burn scars, land cover and ships that run on a small edge NPU — Five Apache 2.0 repositories, each a family of five sizes from 32 thousand to 13.5 million parameters, int8 ONNX files and a version compiled for the Qualcomm QCS8275 NPU on the Arduino VENTUNO Q board. The flood model's 0.19M-parameter "nano" size scores 91.9 mIoU on Sen1Floods11 from Sentinel-2 alone (tying the best published result, an unreleased TerraMind-Tiny variant that also uses radar) and 89.7 on the held-out Bolivia split against 88.9 for Prithvi-CAFE; latency is 3.4 ms per 512 by 512 tile on the board. Scores are the authors' re-scoring of the released files; the other four models' cards were not read in detail. Why it matters: a flood map from a 0.4 MB model on a few-watt board is the kind of result that moves Earth observation from a data centre to the sensor, if the numbers hold up. The lab's country is not stated. Artefacts: weights in ONNX, PyTorch and compiled form (Apache 2.0) · Sizes or variants: pico, nano, tiny, small, medium for each of flood, clouds, burn, land cover, ships · Released: 7 November 2026 (repositories created 23:47 to 23:52 UTC). Source: https://huggingface.co/Civimatica/blue-marble-flood

- Sony publishes OmniUE-3B, an embedding adapter that puts text, images, video and audio into one 2,048-dimension space and accepts boxes, points or audio time spans as part of the query — The checkpoint is a LoRA adapter on Qwen2.5-Omni-3B with SAM-Audio and SAM3 interaction modules bundled; the card reports gains over same-size baselines of +5.1 overall on MMEB-v2 video and +20.7 on SCaR region-level caption retrieval (the 7B size, not in this repository, is the headline in some tables). Licence is "mixed" (third-party components keep theirs), so check it before commercial use. The paper (arXiv 2608.27044) dates from August; the weights are new. This is at the edge of the window (repository created 5 November, 03:08 UTC). Artefacts: weights (mixed licence), code, paper, demo page · Sizes or variants: 3B shown; 7B reported in the paper · Released: 5 November 2026. Source: https://huggingface.co/Sony/OmniUE-3B
