- Privilege escalation in a WordPress "Secure MCP Server" plugin (CVE-2026-131688) — Versions up to 1.5.8 fail to verify authorisation, so a holder of a valid MCP bearer token could escalate to the token owner's administrator role. One of about a dozen AI-branded WordPress plugin CVEs published the same day (NVD keyword search "AI", 21 results in two days), which shows how fast MCP-style endpoints are being bolted onto common software. Spot sold spot-priced compute at up to 90% below on-demand, a niche used for cheap GPU and inference work. Root cause per co-developer Platform9: a compromised credential on an observability system.
