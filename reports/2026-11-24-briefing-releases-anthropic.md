## United States

- OpenAI and Cisco open-source Shirudo, an eBPF runtime for live "shields" on Linux — OpenAI and Cisco released Shirudo on 23 Nov: BSD 2-Clause code (BPF programs dual BSD/GPL) that lets agents (Codex) investigate a vulnerability and draft a temporary eBPF shield that blocks the exploit path in a running system without a restart, with signed shields and TPM-backed load records. The only number is one controlled test: a Codex-generated shield blocked a Java4Shell exploit attempt against a running Elasticsearch service. Limits stated by the post: shields are stopgaps, not patches; operators must review and approve; several capabilities (automated policy generation, broader hardening) are goals, not shipped. Artefacts: code (BSD-2-Clause), documentation, VM quickstart and Isovalent lab · Sizes or variants: n/a (runtime, not a model) · Released: 23 Nov 2026. Source: https://openai.com/index/introducing-shirudo

- Google DeepMind: agent teams on Gemini 4 find cheaper quantum circuits, each result proved in Lean — DeepMind posted on 23 Nov that independent agent teams (meeting every four hours in a "virtual conference", humans setting direction) improved known quantum algorithms and verified every result in Lean. Lab-reported figures: fusion-simulation compute cost cut 11.8x (error-corrected qubits 5,650 to 4,338); cytochrome P450 simulation 2.5x (qubits 481 to 333); a light-sensitive molecule simulation 8x cheaper; one Grover implementation 2.57x; an arcsin routine 290x. Caveat from the post: the optimised circuits would still need more resources than the first error-corrected machines are likely to offer, and the big circuits cannot be run classically, so correctness rests on the Lean proofs. Artefacts: technical report (arXiv 2611.09822), code (Lean library and verified solutions on GitHub) · Sizes or variants: n/a · Released: 23 Nov 2026. Source: https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/
