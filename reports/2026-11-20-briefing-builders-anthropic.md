## Local models and agents

Weight-Space Playground: editing 0.016% of a 0.8B model's weights to stop reasoning loops — A browser demo (llama.cpp compiled to WebAssembly with WebGPU, prompt stays on the device) compares Qwen3.5-0.8B Q4_K_M with an edited copy. The edit subtracts one direction from the ffn_down output weights of 64 neurons in layers 15 and 19 (131,072 of about 800M weights), computed offline with no fine-tuning. The page reports runs hitting the 32k-token limit falling from 93.0% to 33.1% and MATH-500 accuracy rising from 7.9% to 48.1%; these are the builders' own figures on a very weak base model. The page links no code repository, only the underlying experiment write-up and two Hugging Face model pages. On Hacker News commenters criticised the page's presentation and the visibility of human effort, not the technique, and the author rewrote the opening. New here is the interactive demo; the underlying "Sparks of Weight-Space Programming" blog post is older and not counted. Built by: wsxiaoys (TabbyML team page) · Artefacts: demo / write-up / HF model pages (licence not stated) · Signal: 33 HN points, 4 comments. Source: https://tabbyml.github.io/weight-space-playground/

Starbright: a 15 MB speech-to-text model that runs in the browser — A 29M-parameter English-only transcription model (14.9 MB) with a roughly 150 KB gzipped Rust/WebAssembly engine, running in a background worker with about 39 MiB of memory after load. The page claims 4.5-4.9% word error rate on LibriSpeech test-clean, 11.4% on test-other and 13.4-14.0% on FLEURS English (the page gives two different figures for some of these, and its "25x faster than real time" headline does not match its own 59 ms-per-second figure, about 17x). The author's own run on a Ryzen AI Max+ PRO 395 reported 116 ms for a 3.5 s clip. Weights are on Hugging Face (rebreda/starbright-en) under a non-commercial licence; engine source only on request. Built by: quickthoughts (rebreda on Hugging Face) · Artefacts: demo / model weights (noncommercial) · Signal: 3 HN points. Source: https://starbright.quickthoughts.ca/

Rebuilding a local voice assistant pipeline on a Raspberry Pi 5 — Fabio Manganiello (Platypush) rewrote his assistant stack: a new microWakeWord-based wake-word plugin, Silero VAD with WebRTC and energy-detector fallbacks, Whisper (cloud) or Vosk (local) for speech-to-text, any OpenAI-compatible LLM including Ollama, and OpenAI or Piper for speech output. Measured detail: Piper adds about 3-4 seconds on the Pi 5 versus cloud speech output, and in a synthetic benchmark conversations now end 1.0-1.6 s after the last word instead of 6-10 s. No end-to-end latency figure is given. Built by: Fabio Manganiello · Artefacts: code (Platypush plugins, git.platypush.tech) / write-up · Signal: 3 Lobsters points. Source: https://blog.platypush.tech/article/Rewriting-my-voice-assistant-pipeline

bot-inator: a local-first macOS agent that proposes help and writes its own tools — A Python FastAPI daemon with a SwiftUI menu-bar app watches Downloads, mail, iMessages, meetings and app switches, asks an LLM how it could help, and shows an offer card; nothing runs without approval. Default local models run on MLX (Hermes-3-Llama-3.1-8B-4bit, Qwen2.5-1.5B-Instruct-4bit for analysis, Qwen2.5-Coder-14B-Instruct-4bit for drafting), with sqlite-vec for memory; Groq-hosted gpt-oss-120b/20b or any OpenAI-compatible provider is the alternative. Tools the agent writes run in a short-lived Python child process under macOS sandbox-exec, with file, network and command limits, still needing per-call approval (the sandbox can be switched off with an environment variable). Apple Silicon and macOS 14+ only. Very early. Built by: Bforsyth1234 · Artefacts: code (MIT) · Signal: 1 star, 1 HN point. Source: https://github.com/Bforsyth1234/bot-inator

Colab Playground: a desktop app that puts cost guards around Google Colab GPU runtimes — A Rust (GPUI) app driving the Google Colab CLI: multiple accounts, GPU sessions, port forwarding to localhost and plugins, including a bundled one that serves a Hugging Face GGUF model with llama.cpp behind an OpenAI-compatible API and web chat. The interesting part is honesty about limits: auto-stop and idle stop run on the runtime, but the spending cap and balance floor are only checked while the app is open; unknown usage is shown as unknown rather than zero; closing the app does not stop billing. Built by: ScarletKc · Artefacts: code (MIT) · Signal: 296 GitHub stars (created 16 Nov). Source: https://github.com/scarletkc/colab-playground

## Open-source projects and tools

citeparse: a 32M-parameter model that parses references and flags invented citations on a CPU — Converts reference strings to CSL-JSON or BibTeX with small encoder models fine-tuned from Ettin (32M at about 118 references/s on 8 CPU threads, 150M at about 20/s), trained on GROBID's citation corpus and Crossref records; a `check` command then looks up DOIs and searches Crossref and OpenAlex to flag references that match no real work. Author-reported: on 700 real Crossref references the 150M model gets 83.4% fully right versus 71.1% for GROBID 0.8.1, but GROBID wins on its own held-out set (0.943 vs 0.900 field accuracy); in the checker test 80 of 83 fabricated references were reported as not found and none of 100 real ones were wrongly flagged. Relevant to anyone checking LLM-written bibliographies. Built by: un-seen (models under hedwigai on Hugging Face) · Artefacts: code and models (Apache-2.0) · Signal: 1 star, 1 HN point. Source: https://github.com/un-seen/citeparse

motlab: video as code, with agent skills that write the scenes — Each scene is a canvas page with a `renderAt(t)` function; a web viewer plays it frame by frame and lets you leave notes on frames, boxes or time ranges, which the agent reads back from `selection.json` to revise. Export renders MP4 at 720p to 4K in headless Chrome using WebCodecs; a second skill builds reusable asset kits (icons, 2D characters, transitions, 3D objects via Blender). No AI image or video models are used. Skills install for Claude Code, Codex, Cursor, Copilot, Gemini CLI and others. The README says it is young and tested mainly on one Windows laptop. Built by: staryone · Artefacts: code (MIT) · Signal: 224 GitHub stars (created 16 Nov). Source: https://github.com/staryone/motlab

craft: design skills for coding agents — A set of skills where `craft-setup` interviews you and writes a DESIGN.md brief, then `craft` lists the screen's states, draws it with the design system's parts and checks its own output; companions cover exploration, critique, system maintenance and design-to-code sync. Adapters for Paper, pen.dev, Figma and plain HTML (the Figma adapter is untested in real runs, per the README). In Claude Code a session-start hook routes requests; other agents need routing rules pasted into AGENTS.md. Built by: diego3g · Artefacts: code (MIT) · Signal: 275 GitHub stars (created 15 Nov). Source: https://github.com/diego3g/craft

poo: find and safely free disk space eaten by dev work and agent worktrees — A macOS menu-bar app, CLI (also Linux) and MCP server that sorts build output, caches, simulators and agent worktrees into tiers by rebuild cost, deletes only after review, and can back up a worktree before removing it. It maps Xcode DerivedData to its checkout, checks each worktree for uncommitted work and landed changes, and covers Claude Code, Codex, Conductor and Cursor; a checkout with an open agent, editor or shell counts as "warm". A small sign of what running many parallel agents does to a laptop disk. Built by: morajabi · Artefacts: code (MIT) / site poo.morajabi.com · Signal: 80 GitHub stars (created 15 Nov). Source: https://github.com/morajabi/poo

gh-sift: one terminal app for the whole GitHub PR review — A Go GitHub CLI extension and single binary: PR lists from your gh-dash config, full PR view with threads and merge status, stacked-PR-aware merging, Actions views that open on the failure, split or stacked diffs, read tracking synced with GitHub's Viewed checkbox, and inline comment, suggest, resolve and approve. Pre-1.0. Relevant to reviewers drowning in agent-written PRs, though the README does not frame it that way. Built by: chrismatix · Artefacts: code (MIT) · Signal: 0 stars, 2 HN points. Source: https://github.com/chrismatix/gh-sift

Openspot: macOS launcher where a "tool" is any script that prints a few lines — Each spot is an executable plus a `spot.toml`; Openspot turns its plain-text output into native SwiftUI panels opened with a hotkey, with hot reload. Spots from others run under sandbox-exec; your own run with Openspot's permissions. Draft protocol, beta, macOS 26+. Built by: celishq (small team, "we" in README) · Artefacts: code (MIT) · Signal: 3 stars, 5 HN points. Source: https://github.com/celishq/openspot

Billet: a free live board for the Markdown task files coding agents write — Tasks are Markdown files in `docs/tasks/` with a JSON header (status, order, blockers, branch); a set of `billet-*` skills (add, start, finish, merge, split, groom and others) lets any skills-capable agent manage them, and the app only displays the board and never calls a model. The app is free but closed source; the task format and skills are open (zlib). Built by: Michael Kutowski · Artefacts: skills on GitHub (zlib), app closed · Signal: 3 HN points. Source: https://mktwsk.xyz/billet/

## Agents and automation

Vestige: deterministic agent memory with no embeddings and no LLM — A local MCP server (Rust) storing memories in an append-only, hash-chained, signed log (BLAKE3 digests, bi-temporal validity) and retrieving them with spaced-repetition-style decay, "retroactive salience backfill" and deterministic rules, on CPU only. The README's retrieval numbers (builder's own, run on a 2011-era Intel i5 with 8 GB RAM, with a reproduction script): LongMemEval-S session-level Any@1 90.00% and Any@5 97.45%; at turn level Any@1 54.26%; LoCoMo-10 turn-level R@1 47.92%; the page says these are retrieval scores, not answer accuracy. Note the repository dates from January 2026; the Show HN launch of this retrieval design is the news. Built by: Sam Valladares · Artefacts: code (AGPL-3.0) · Signal: 661 GitHub stars, 2 HN points. Source: https://github.com/samvallad33/vestige

agentest: 165 offline checks of what an agent actually did, read from its OpenTelemetry traces — Runs deterministic pass/fail/n-a checks (unearned success claims, acting before verifying, following hidden instructions, unauthorised tool calls, personal-data leaks) over traces the agent already recorded, with no API key and no LLM judge, so the same trace always gives the same verdict. Importers for LangGraph, OpenAI Agents SDK, AutoGen, smolagents and n8n; optional A2A AgentCard and MCP tool lists add checks. On PyPI as agentest-ai 3.5.0. The author is the CTO of an AI-assurance company, so it is partly a vendor's open-source entry. Built by: Srinivas Padmanabhuni (AiEnsured) · Artefacts: code (Apache-2.0, checklist data CC BY 4.0) · Signal: 16 stars, 2 HN points. Source: https://github.com/srpadmanabhuni/agentest

dayfile: an append-only log for scripts and agents, served as feeds and over MCP — SQLite with append-only enforced by triggers, behind a Python/uvicorn service; anything that can send an HTTP request adds events, and the log is exposed as JSON Feed, Atom, CloudEvents, a JSON API and an MCP server so an assistant can read and write it. Self-hostable or hosted at dayfile.app. Repository created 18 Nov. Built by: dayfile account (no named author) · Artefacts: code (AGPL-3.0) · Signal: 0 stars, 4 HN points. Source: https://github.com/dayfile/dayfile

Agent Crop: local timing and self-retrospectives for coding agents — Records where agent session time goes (active vs waiting on the user, tool calls and failures, repeated failures and repeated edits to the same place, agent-reported phases with a required cause when blocked), nudges a stalled agent, and has the agent write retrospectives back into its own instructions, skills or tools. Data stays in ~/.agentcrop/data and conversation text is not stored. Works with Claude Code, Codex and DeepSeek Harness; README is Chinese with English summary. Built by: oriliz · Artefacts: code (MIT) · Signal: 135 GitHub stars (created 14 Nov). Source: https://github.com/oriliz/agent-crop

Parallax: a hands-off plan, review, execute, audit loop for coding agents — Skills for alignment questions, hand-off, independent plan review, execution in a fresh session via a `/clear` hand-off verified against the transcript, an independent post-execution audit, a scoped commit and a wrap-up; solo mode or team mode with an orchestrator and a separate headless executor. Runs on Claude Code and on DeepSeek Harness (npm package parallax-dsh, which sets subagent depth to 3). Tested on Linux and WSL, macOS untested. Built by: AI4XE organisation (no named author) · Artefacts: code (MIT) · Signal: 136 GitHub stars (created 15 Nov). Source: https://github.com/AI4XE/Parallax

## Experiments, demos and write-ups

lemo-animi: stop-motion shorts from one sentence, with "images make it look right, code makes it move" — Instead of video generation, an image model (via Codex) draws character sheets, backgrounds and action sheets in one of eight material styles, the pipeline cuts them into cells and animates them in code, then adds an original score, foley and optional narration, with a local review page for notes before delivery. The README recommends Codex with a GPT-6.2 image-capable model; Claude Code can drive it but needs Codex for drawing. Non-commercial licence, so not open source in the usual sense. Built by: Lemomo (LemoLab) · Artefacts: code (CC BY-NC 4.0) · Signal: 137 GitHub stars (created 16 Nov). Source: https://github.com/lemomo-ai/lemo-animi

ADE Index: a sourced ranking of 1,000 agentic coding tools — A directory of 1,000 tools (383 agent workspaces, 121 ranked) with every listed fact linked to its source sentence (22,935 sources claimed). The rank is based on Hacker News discussion over 90 days with a half-life decay, upvotes capped at 20% of the score, maker self-votes excluded, GitHub stars shown but not scored. Made by the team behind the workspace app atrium, which is listed like the others and disclosed; the data and code are not stated to be downloadable, so the ranking is the builder's own and unaudited. Built by: atrium team · Artefacts: demo / methodology page · Signal: 25 HN points. Source: https://adeindex.com
