## 1. United States

- **Ai2 open-sources AstaBrief 8B, the fast report-writing model behind Asta** — Ai2 released the weights and training data for AstaBrief, an 8B model fine-tuned from Qwen3-8B. It turns a research question plus retrieved literature excerpts into a cited scientific report in a single pass. It was trained with SFT and DPO on real Asta user queries, with citation-focused filtering, rather than with RL. In Asta, the "Fast mode" it powers averages 51.1 s per report, against 178.5 s for the Claude-based Thinking mode. Ai2 says most of the evaluation was done in 2025 against the frontier models of that time and has not been rerun, so the quality comparisons are dated and are the lab's own. It also ships an example workflow for writing reports from local PDFs.
  Artefacts: weights (Apache 2.0) · training data · technical write-up · Sizes or variants: 8B (base Qwen3-8B) · Released: 2 October 2026
  Source: https://huggingface.co/blog/allenai/astabrief

- **NVIDIA releases PixelUMM, an encoder-free model that understands and generates images and video in pixel space** — PixelUMM is a 15.2B decoder-only Transformer built on Qwen3-8B. It reads RGB images and video frames as raw 16×16 pixel patches instead of using a separate vision encoder, and it generates them with an iterative denoising head. One shared representation handles text-to-image, image- and video-conditioned text, and video generation. This makes it a concrete open checkpoint for testing whether unified multimodal models need a pretrained vision tower at all. It is for research only and requires Linux, an NVIDIA GPU and FlashAttention.
  Artefacts: weights (NVIDIA One-Way Noncommercial License) · model card · Sizes or variants: 15.2B · Released: 1 October 2026 (Hugging Face upload, 21:40 UTC)
  Source: https://huggingface.co/nvidia/PixelUMM

- **Perplexity open-weights pplx-decider-v1-27b, a decision model fine-tuned from Qwen3.8-27B** — Perplexity's first open-weight model in this category is a classifier and router. It returns a selected choice with calibrated probabilities, or a yes/no probability, over text and images, with criteria defined in the request. On Perplexity's own 11-benchmark table it averages 85.71%, against 84.51% for Jev and 74.76% for the base Qwen3.8-27B. It wins on RAGTruth (88.8%) and FinancialPhraseBank but trails Jev on BBH and WinoGrande. The weights need about 49 GiB of GPU memory. It joins the cluster of "decision model" releases this week, alongside Cloudflare's Clef and llama.cpp's new decision-model support.
  Artefacts: weights (Apache 2.0) · model card · inference code · Sizes or variants: 27B · Released: 1 October 2026 (Hugging Face upload, 21:24 UTC)
  Source: https://huggingface.co/perplexity-ai/pplx-decider-v1-27b

- **Microsoft AI launches MAI-Transcribe-2-Streaming and the MAI-Voice-2.1 speech models** — MAI-Transcribe-2-Streaming is Microsoft AI's first streaming speech-to-text model. It covers 60 languages with continuous language detection and returns its first partial transcripts about 100 ms after receiving audio. Microsoft says it ranks first on Artificial Analysis for both partial and final accuracy. MAI-Voice-2.1 (23 languages, 26 locales, one voice across all languages, $22 per 1M characters) and MAI-Voice-2.1-Flash (150 ms end-to-end latency, $15 per 1M characters) complete the voice-agent stack, and both clone a voice from a few seconds of reference audio. The benchmark and latency claims are Microsoft's own.
  Artefacts: API only · Sizes or variants: Transcribe-2-Streaming ($0.54 per audio hour introductory, through end of 2026), Voice-2.1, Voice-2.1-Flash · Released: 1 October 2026
  Source: https://microsoft.ai/news/our-first-streaming-transcription-model/

## 2. Europe

- **Black Forest Labs ships FLUX 3 Image through its API, with bounding-box layout and pixel-exact editing** — FLUX 3 Image is the image part of BFL's multimodal FLUX 3 model. It uses one endpoint for both generation and editing, and the prompt decides which. A JSON table of bounding boxes appended to the prompt places each element on a 0–1000 grid, and local edits change only the marked elements. It accepts up to ten reference images and renders natively at up to 4K (about 16 MP) in 15 aspect ratios. Web and image "grounding" is on by default. BFL also pitches it as agent-friendly: an LLM plans the layout table and the image model renders inside it. Weights are offered only under a commercial self-hosting licence on request.
  Artefacts: API · commercial weights licence on request · docs · Sizes or variants: resolutions 768sq ($0.041), 1k ($0.048), 2k ($0.100), 4k ($0.607) per image · Released: 1 October 2026
  Source: https://docs.bfl.ai/release-notes

## 3. China

- **BAAI releases AREX-2, a 27B agent model trained to improve its own solutions over many test-time rounds** — AREX-2 learns a propose–measure–reflect–revise loop on machine-learning and algorithmic-programming tasks with verifiable feedback, using scores, logs, errors and timings as signals. BAAI reports that this behaviour transfers to deep research without new search trajectories. The model is a dense 27B built on Qwen3.8-27B, accepts images, and has a 262,144-token context. In BAAI's own tables it scores 70.7 on Frontier-CS (agent track) and 81.8 on MLE-Lite "any medal". That puts it ahead of much larger open models such as Kimi-K3, and on MLE-Lite ahead of the closed GPT-5.6 Sol. These are the lab's own numbers under its own protocols. It surfaced late: it was uploaded on 29 September and appears in no earlier briefing.
  Artefacts: weights (Apache 2.0) · paper (arXiv 2609.38288, v1 29 September 2026) · code · Sizes or variants: 27B · Released: 29 September 2026
  Source: https://huggingface.co/BAAI/AREX-2
