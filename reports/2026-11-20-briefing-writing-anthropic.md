## 1. Deep dives and technical write-ups

- Frontier models write a working MNIST classifier by setting 5,994 weights directly, with no gradient descent — Lex Toumbourou gave Claude Fable 5.2 a fixed CNN and let it set every weight through code, with feedback (loss, accuracy, confusion matrix) for up to 50 steps and the test set never shown. Three Fable runs reached 88–91% test accuracy (Adam after 50 gradient steps: about 91%); Opus 5.5 reached about 72%. The best run built hand-drawn templates, loop and corner detectors and naive-Bayes-style scoring, then measured its own features and rebuilt the classifier from the measurements. On 64x64 cats-vs-dogs it reached only 61.6% (Adam after 5,000 steps: 74%) at $8.08 for 17 steps, settling on crude image statistics (green, texture, edge direction). Toumbourou's argument is that the models are chaining classical hand-built techniques, not discovering a new way to program networks; the limits show as soon as the task gets harder. What is new: weight-space programming has been covered before; this is an independent replication with a newer model, a cost figure and a negative result on the harder task. Companion item: TabbyML's browser demo (19 Nov, Show-HN-style page) of one reported weight edit: subtracting one direction from 64 neurons' output weights in layers 15 and 19 of Qwen3.5-0.8B (about 131,072 of roughly 800M weights, no fine-tuning) cut runs hitting the token limit from 93.0% to 33.1% and raised MATH-500 from 7.9% to 48.1%, and it runs in the browser through llama.cpp on WebAssembly/WebGPU after a 1.05 GB download. The 0.8B numbers are the TabbyML team's own and I did not reproduce them. - Three frontier models reverse-engineer lost OCaml code behind Apache DataSketches' CpcSketch tables — tison, a ScopeDB engineer maintaining the Rust port, found four sets of hardcoded lookup tables (Huffman, column permutations, polynomial coefficients, confidence intervals) whose generator, Kevin J. Lang's OCaml code, was lost after Lang's death in 2019. He used Gemini 4 Carbon for initial synthesis, Claude Opus 5.5 for falsification (ablations, Monte Carlo) and GPT 6 Astra for mutation testing, with the checked-in tables as a numerical oracle. All 5,697 Huffman codewords across 23 tables were reproduced bit-for-bit, and all 16 permutation tables match. Polynomial coefficients are recoverable only up to lg_k 7 (condition numbers near 10^17 above that). An explanation that looked convincing ("left-edge truncation") was ruled out by tests, and mutation testing exposed tautological assertions. The author is explicit that matching artifacts does not prove it is the original code, and lists six open questions. Worth reading as a model of using several models adversarially against a hard oracle. The page shows no date; Hacker News submission 16 November. - Claude Fable 5.2 predicts protein sequence far better than rivals and some protein language models — Xinming Tu (with Leo Tianlai Chen for an appendix) asks models to continue a protein after a cut, scoring the first of the next 10 residues, on 668 little-studied bacterial and archaeal proteins from 167 unknown-function Pfam families, each also scored on a shuffled version so the gap isolates knowledge of sequence order. Fable 5.2 scores 54% on real versus 9% shuffled (+45.1 points); Opus 5.5 +27.4; GPT, Gemini and seven open-weight models stay at roughly 0–3 points. The protein language models ProGen3-3B (+32.5) and ProtGPT3-10B (+27.7) trail Fable 5.2. Gaps persist in 128 families with no papers and in 56 proteins first published in August 2026 (Fable +22.1, GPT-6.2 Sol -0.4), and non-thinking answers are as accurate as thinking ones. Famous proteins are recited, so those do not separate memorisation from learning. An independent, single-author benchmark; read the appendix on post-cutoff proteins before accepting the headline. - Fake "AI crawlers" are secrets scanners hunting your AI tool configs — Ege Demir logged three scanners on ten sites from late September to 18 November. Octopus uses 32 user agents (7 undocumented, 25 copied from real crawlers), 97 Google Cloud machines in 15 regions (65 gone within an hour) and 457 paths; Gecko, a .NET tool with a truncated Chrome 128 user agent, sends about 206 requests in 0.86 s and grew its AI-tool target list from 4 to 26 paths in five weeks (Claude Code settings, Codex and Cursor configs, LLM CLI keys), AI files rising from about 4% to about 10% of its requests; Tortoise is a small Go tool at one request per 1–7 s. ## 3. Prompting and context techniques

- Elephant-Goldfish Model: draft with full context, review with agents that have none — Google's open-source (Apache 2.0, "not an officially supported Google product") plugin google/elephant-goldfish-model, credited to Dave Rensin's article on elephants and goldfish, formalises a pattern: one agent that knows the project drafts a spec; fresh subagent reviewers, who never saw the conversation, read only the written document and the sources it references, and report what is missing or unclear. The workflow runs from brainstorming to a concept brief, design document, review, resolution of findings, then implementation, and the review stops if the host cannot create fresh subagent contexts. The README says it does not replace tests or human judgment, and gives no measured results; the egm.dev example shows three gaps found in a study-space plan (no named staffing, unstated opening hours, an invisible Friday rule). The technique can be tried by hand with any agent that can start a clean subagent. Evidence level: practitioner pattern with a worked example, not evaluated. The repository's creation date was not readable (the GitHub API returned 403); Hacker News submission 16 November. - OpenAI's GPT-6.2 Astra and Sol prompting and migration guide: shorter prompts, stated assumptions, stable prefixes — OpenAI's developer guide says both models are more concise and direct by default, so existing "be concise" lines should be revisited; tells prompts to specify the outcome and which decisions need the user, letting the model make reversible assumptions and state them and pause only for major scope changes, blockers or irreversible actions; asks the model to confirm every part of the request is handled before finishing; and for coding to describe conventions and reuse existing logic. Migration: start at `reasoning.effort` medium (low if you used none or minimal), use the Responses API, drop `temperature` and `top_p`, avoid editing earlier turns (it drops reasoning items and hurts caching) and keep stable instructions in a leading developer message. The page carries no date; GPT-6.2 launched on 17 November, so it is very likely inside the window, but treat the date as unverified. The vendor reports no measurements on this page.
