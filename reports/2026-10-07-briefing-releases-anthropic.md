## United States

- **Google releases EmbeddingGemma 2, a 740M-parameter open multimodal embedding model with a text-only mode of 270M** — One embedding space now covers text, code, images, video and audio. The model is built on the Gemma 4 architecture and is modular: 270M for text, plus optional 170M vision and 300M audio encoders. Output vectors are 768-dimensional and can be truncated to 512, 256 or 128 with Matryoshka training. The context window is 8K tokens (4x EmbeddingGemma 1), and Google says it needs about 191 MB of active RAM for quantised text-only weights and about 567 MB for the full multimodal model on a Pixel 11 Pro. Google's own figure for code retrieval is a rise on MTEB Code from 68.76 to 78.68, and it claims best-in-class results among sub-1B multimodal embedders; all benchmark claims are the lab's own. It matters for local setups because it runs in transformers, sentence-transformers, llama.cpp, vLLM, Ollama, LM Studio, MLX and transformers.js, and shares a tokenizer and audio encoder with Gemma 4, so both can sit in one on-device RAG pipeline. Artefacts: weights (Apache-2.0; Hugging Face and Kaggle) / model card / developer guide · Sizes or variants: 740M total (270M text, 170M vision, 300M audio) · Released: 6 October 2026 (DeepMind blog, 19:57 UTC; Hugging Face model page updated the same day). Source: https://deepmind.google/blog/embeddinggemma-2-an-open-lightweight-multimodal-embedding-model/ Weights: https://huggingface.co/google/embeddinggemma-2

- 🚨 **OpenAI publishes 722 mathematics manuscripts written by an unreleased internal model, with Lean proofs for many** — OpenAI released a GitHub collection of 722 manuscripts in 372 families, which it says an internal model produced from about 4,000 open research problems, using on average three hours of ChatGPT Pro thinking compute per result. The catalogue lists claims such as a zero-free half-plane Re(s) > 7/8 for Dirichlet L-functions including zeta (with an alternate 11/12 proof), Milne's rationality conjecture, and an odd 2-adic Fontaine-Mazur modularity result. The HN thread (440 points) also singles out a Unique Games Conjecture manuscript, which I did not open. Not all papers have Lean formalisations; OpenAI itself warns that unformalised results may contain errors and will be corrected as versions. It also releases abridged reasoning summaries for ten result families. Nothing here is independently verified yet, and the HN discussion is as much about how OpenAI handled the maths community (credit, scooping, earlier disputes) as about the mathematics. The model is not released. - **EmpirioLabs opens the weights of Aplomb 1, a 5.3B "decision model" with a 1M-token window, under a restrictive licence** — A start-up (the page names EmpirioLabs.ai LLC; location not stated) takes Qwen3.5-4B, adds the audio encoder from Qwen3-Omni-30B-A3B, extends the window from 262K to 1M tokens and adds its own decision head. ## Europe

- 🚨 **Mistral previews Mistral Large 4, a 1T-parameter open-weight multimodal MoE, with weights promised by the end of October** — The preview API is live on Mistral Studio now. Mistral's post says 1 trillion total and 49B active parameters, trained from scratch on 3,800 NVIDIA Grace Blackwell GPUs in its own European data centres; the docs page lists 1.05T total, 52B active and a 1.6B vision encoder, so the figures differ by source. It is a hybrid instruct-and-reasoning model with image input, a 1M-token context window and training data in more than 160 languages. The pitch is cybersecurity: Mistral cites the Artificial Analysis Cyber Index (top five overall, 82% on the reproduce-then-patch test) and 93% on Cybench, and argues closed models score near zero on such tests because they refuse. Coding scores include 61.7% on DeepSWE v1.1 and 28.3% on Terminal-Bench 4, and a blind Surge AI human rating puts it second of five (3.74) behind Claude Opus 5 (4.22). Nearly all numbers are Mistral's own, with some from named third-party evaluators (Artificial Analysis, vals.ai, Lakera, Surge). Until the weights drop, Mistral is red-teaming with security partners and state authorities. Preview API pricing is $1.36 per million input tokens and $4.18 output. Weights licence, architecture details and a technical report are all still to come. HN gave the launch 1,593 points. ## Tools, APIs and platform updates

- **OpenAI releases the Decisions API in public beta, with one model and a general release promised in weeks** — A new POST /v1/decisions endpoint takes text and/or images and returns typed answers: a probability that a condition holds (predicate), a choice from a fixed set, or a probability-weighted score against ordered levels. OpenAI says it is about 10x faster than the Responses API. Only gpt-6-luna is supported for now; SDK support starts at Python 3.26.0 and JavaScript 7.30.0, and answers can also come back as refusals. The changelog dates the release 6 October, together with a simplification of API usage tiers from five to three (Build, Launch, Grow). Earlier briefings only mentioned the API from a DevDay interview and a calibration preview; this is the first public documentation. For builders the notable point is that the calibration of those probabilities is now the product's central claim, and Aplomb 1 and Liquid d1 above arrive at the same time with the same idea.
