- Build the Workshop Before the Software Factory — Armin Ronacher, Earendil (AI Engineer). Ronacher, whose company Earendil builds the Pi coding agent, argues that the agent's core toolset is the same as a year ago and that the gain comes from better models. He shows his own session data: fewer corrections from him, agent tasks running 14 minutes instead of about 2.5, and 141 projects started with only 10 to 15 still maintained. His thesis is that human attention is still the bottleneck, so teams should first build a "workshop" that produces excellent software and only then a "factory" that produces more of it. The chapters also cover when to push back on an agent, executive summaries instead of reading all code, open file formats, durable agents that suspend and resume, and code mode with classifier models.
