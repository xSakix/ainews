## Rest of the world

- AI21 Labs (Israel) open-sources Teel, a Python runtime that overlaps independent model and tool calls without async code — You write sequential Python, mark expensive functions with `@cacheable` and orchestration with `@jit`, and a "shadow interpreter" reads ahead through the bytecode and starts calls whose arguments are already known on background threads. AI21 reports 83 percent less runtime on average (8.07x on the longest run, 307 s to 38 s) on Princeton's Tree of Thoughts code left unmodified, 2.58x on a synchronous Python recursive-language-model setup in LangChain Deep Agents, and 1.22x against model-written async JavaScript. A small code-review agent takes 7.1 s sequentially, 3.0 s hand-rewritten with asyncio and 2.9 s with Teel. The catch is stated in the post: Teel currently needs exactly Python 3.12.13. The results are the lab's own. Artefacts: code (open source, GitHub AI21Labs/teel) / technical post · Sizes or variants: not applicable · Released: 5 November 2026.
