## Safety and security

- Cursor publishes its post-mortem: the October backdoored Claude Code extension started with a Cursor-issued access key that Fireworks AI exposed — Cursor blog (13 November, 12:00 UTC), summarised by Unite.AI (13 November, 20:34 UTC). New since the 29-31 October and 9-11 November reports: the attacker used the key to copy a read-only bucket of historical coding-agent traces (mostly 2025, from sessions not in Privacy Mode, which Cursor was allowed to use for training). A few traces held unredacted credentials (under 0.01% of customers had API credentials exposed; under 0.05% of non-Privacy-Mode users had traces exposed). Those credentials opened select SaaS tools, archived non-production repositories, support emails and credentials users had sent to support, and on 29 October let the attacker place malicious copies of Anthropic's Claude Code extension on the cache serving Cursor's marketplace. At most 5,000 users who requested specific cached versions got the build, which was live about 11 hours; Cursor says Anthropic did not publish it and its product was not vulnerable, and Open VSX never carried it. Cursor rotated every exposed credential, rebuilt the marketplace and, per Unite.AI, moved all inference traffic off Fireworks. The lesson for anyone sending agent traces to a vendor for training or evaluation: redaction failures travel with the data. Source: https://cursor.com/blog/security-incident-update
