## Agents and memory

- Coding agents used repository memory to solve more tasks with fewer steps and tokens — CoReMem values trajectory segments on the next unknown task and builds compact memory around repository locations and executable checks. On ChainSWE, a 27B actor's resolve rate rose from 21.0% to 25.7%, with 17% fewer steps and 11% fewer cache-aware tokens than the untrained actor without memory. Authors: Peiwen Li et al. · First submitted: 12 Nov 2026 · Artefacts: paper. Source: https://arxiv.org/abs/2611.17316

- Evolved agent-memory programs beat hand-designed baselines at 35% of serving cost — MAPE searches whole memory programs and found two recurring patterns: retain raw conversations as evidence, then compose retrieved evidence for the query. It gained up to 12 percentage points on LoCoMo and LongMemEval, and its composition module improved five existing memory systems. Authors: Xinheng Ding et al. · First submitted: 12 Nov 2026 · Artefacts: code and paper. Source: https://arxiv.org/abs/2611.17068
