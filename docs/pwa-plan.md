# Plan: install AI News Daily as an Android app (PWA)

**For:** the agent implementing this (Sonnet 5.5 or GPT).
**Status:** planned, not implemented. Every file below was built and tested on
2026-10-29 against Hugo 0.148.2 extended (the CI version) and headless
Chromium. All 7 editions produced a manifest, Chrome's
`Page.getInstallabilityErrors` came back empty, and reading offline worked.
Copy the reference code as given; don't redesign it. If something here turns
out to be wrong, fix it and note the change in your PR description.

## What readers get

- Chrome on Android offers **Install app**, either as a prompt or from the
  ⋮ menu. The AI logo goes on the home screen, and the site opens full screen
  without the browser bar, behind a dark splash screen showing the logo.
- The app opens the edition it was installed from: installing on `/sk/` gives
  an app that opens the Slovak home page.
- Long-pressing the icon shows **Archive / Topics / Search** in that edition's
  language.
- The last 60 pages a reader opened still work offline. Any other page shows an
  offline page in the edition's language, listing the pages that are saved.
- Desktop readers see no difference.

## How the site works today (what the implementer needs to know)

- **Hugo 0.148.2 extended** with the **PaperMod** theme. The theme is a git
  submodule, so run `git submodule update --init` before building.
  Cloudflare builds and deploys on every push to `main`. `public/` is not
  committed.
- **Seven editions:** `en` at the site root, plus `sk nl fr de es zh` under
  `/<lang>/` (see `[languages]` in `hugo.toml`).
- **`canonifyURLs = true`:** every `href`/`src` in the built HTML is made
  absolute (`https://ai-news-daily.xyz/...`). For local testing, build with
  `--baseURL http://localhost:<port>/`, or pages will load CSS from the live site.
- **`params.env = "production"`** is always set, so `hugo server` *also* looks
  like production to templates that test it. Use `hugo.IsProduction`, which is
  false under `hugo server`, for anything that must not run in development.
- **PaperMod `head.html`** already emits the favicons, `apple-touch-icon`,
  `theme-color` `#1d1e20` (from `[params.assets]`), and `.AlternativeOutputFormats`
  as `<link rel=alternate>`. Our hook files are
  `layouts/partials/extend_head.html` (exists) and
  `layouts/partials/extend_footer.html` (the theme's copy is empty; create ours).
- **Custom home output formats already exist** (`llms`, `llmsfull`), with
  templates named `layouts/index.<format>.<suffix>`. The manifest follows the
  same pattern.
- **CSS/JS are fingerprinted** under `/assets/` and cached as immutable in
  `static/_headers`.
- **Icons:** `static/logo-512.png` is 512×512 with transparent rounded corners
  on a `#1d1e20` background. There is no 192 px icon and no maskable icon yet.
- **CI** (`.github/workflows/check-site.yml`) runs `scripts/check_*.py`, then
  `hugo --minify --panicOnWarning`. A warning fails the build.
- A daily content pipeline commits to `content/`, `reports/` and `prompts/`
  many times a day. **Don't touch those directories.**

## Decisions (already made; don't reopen them)

1. **One manifest per edition, generated by Hugo** as a custom home output
   format. `id` and `start_url` are the edition's home page, so each edition
   installs as its own app. `scope` is `/`, so links to other editions stay
   inside the app.
2. **Ship a service worker.** Chrome no longer requires one to install, but
   offline reading is what makes a news app worth installing. Caching rules:
   - **Pages:** network first, falling back to the cache after 4 s. The site is
     news, so an online reader must never see yesterday's home page.
   - **`/assets/`:** cache first (the files are fingerprinted).
   - **Images and fonts:** stale-while-revalidate.
   - **Search index:** network first.
   - **Everything else** (RSS, `index.md`, `llms*.txt`, other origins) is left
     alone.
3. **No precaching of content.** Only the offline page and one icon are
   precached. Caches are capped at 60 pages, 30 assets and 80 images.
4. **The offline page lives at `/offline/`** (`static/offline/index.html`),
   **not** `/offline.html`. Cloudflare redirects `*.html` to the extensionless
   URL, and a navigation can't be answered with a redirected response. The
   page is self-contained (inline CSS and JS), so it works with nothing else
   cached.
5. **The service worker is registered only when `hugo.IsProduction`**, so
   `hugo server` never installs one on `localhost:1313`.
6. **`short_name` is "AI News".** Android truncates "AI News Daily" under the
   icon.
7. **`background_color` and `theme_color` are `#1d1e20`**, matching the logo
   background and the existing `theme_color`, so the splash screen matches the
   icon.
8. **Out of scope:** an in-page "Install" button, push notifications, and a
   Play Store listing (see the end of this plan).

## Step 1: Icons

Generate the icons once and commit the PNGs. Don't commit this script; the
repo's scripts use only the Python standard library. (If Pillow is missing,
run `pip install pillow`.)

```python
from pathlib import Path
from PIL import Image

Path("static/icons").mkdir(exist_ok=True)
logo = Image.open("static/logo-512.png").convert("RGBA")
logo.resize((192, 192), Image.LANCZOS).save("static/icons/icon-192.png", optimize=True)
# Maskable: Android crops the icon to a circle or squircle, so the logo sits
# in the central 80% of a full-bleed square in the logo's own background colour.
canvas = Image.new("RGBA", (512, 512), (0x1D, 0x1E, 0x20, 255))
canvas.alpha_composite(logo.resize((410, 410), Image.LANCZOS), (51, 51))
canvas.convert("RGB").save("static/icons/maskable-512.png", optimize=True)
```

The resulting files are about 7 KB and 12 KB. The 512 px "any" icon reuses
the existing `/logo-512.png`. To check the maskable icon, open it on
<https://maskable.app/> or just look at it: the background must reach every
edge, and the logo must stay clear of them.

## Step 5: `static/sw.js` (new)

The file must be served from the site root, because its scope is `/`.

```js
// Service worker for AI News Daily: makes the site installable as an app
// and keeps recently read pages available offline (see docs/pwa-plan.md).
// Bump VERSION only when this file's caching logic changes; new articles
// and new CSS/JS need no bump (pages are network-first, assets fingerprinted).
const VERSION = 'v1';
const PAGES = `ainews-pages-${VERSION}`;
const ASSETS = `ainews-assets-${VERSION}`;
const IMAGES = `ainews-images-${VERSION}`;
const CORE = `ainews-core-${VERSION}`;
const OFFLINE_URL = '/offline/';
const CORE_URLS = [OFFLINE_URL, '/icons/icon-192.png'];
const LIMITS = { [PAGES]: 60, [ASSETS]: 30, [IMAGES]: 80 };
const NETWORK_TIMEOUT_MS = 4000;

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CORE).then((cache) => cache.addAll(CORE_URLS)).then(() => self.skipWaiting())
  );
});

self.addEventListener('activate', (event) => {
  event.waitUntil((async () => {
    const keep = new Set([PAGES, ASSETS, IMAGES, CORE]);
    for (const name of await caches.keys()) {
      if (name.startsWith('ainews-') && !keep.has(name)) await caches.delete(name);
    }
    await self.clients.claim();
    // The page that registered the worker loaded before it existed;
    // cache it now so the start page also opens offline.
    const pages = await caches.open(PAGES);
    for (const client of await self.clients.matchAll({ type: 'window' })) {
      try { await pages.add(client.url); } catch (e) { /* offline or redirected */ }
    }
  })());
});

self.addEventListener('fetch', (event) => {
  const { request } = event;
  if (request.method !== 'GET') return;
  const url = new URL(request.url);
  if (url.origin !== self.location.origin) return;

  if (request.mode === 'navigate') {
    event.respondWith(pageResponse(event));
  } else if (url.pathname.startsWith('/assets/')) {
    event.respondWith(cacheFirst(request, ASSETS));
  } else if (url.pathname.endsWith('/index.json')) {
    // Search index, so search keeps working offline.
    event.respondWith(networkFirst(request, PAGES));
  } else if (request.destination === 'image' || request.destination === 'font') {
    event.respondWith(staleWhileRevalidate(event, IMAGES));
  }
  // Everything else (RSS, Markdown copies, llms.txt, ...) goes straight to the network.
});

async function pageResponse(event) {
  const { request } = event;
  const cache = await caches.open(PAGES);
  try {
    const response = await withTimeout(fetch(request), NETWORK_TIMEOUT_MS);
    if (response.ok && response.type === 'basic') {
      event.waitUntil(cache.put(request, response.clone()).then(() => trim(PAGES)));
    }
    return response;
  } catch (e) {
    const cached = await cache.match(request, { ignoreSearch: true });
    if (cached) return clean(cached);
    const offline = await caches.match(OFFLINE_URL);
    return offline ? clean(offline) : Response.error();
  }
}

async function networkFirst(request, cacheName) {
  const cache = await caches.open(cacheName);
  try {
    const response = await fetch(request);
    if (response.ok) await cache.put(request, response.clone());
    return response;
  } catch (e) {
    return (await cache.match(request)) || Response.error();
  }
}

async function cacheFirst(request, cacheName) {
  const cache = await caches.open(cacheName);
  const cached = await cache.match(request);
  if (cached) return cached;
  const response = await fetch(request);
  if (response.ok) { await cache.put(request, response.clone()); trim(cacheName); }
  return response;
}

async function staleWhileRevalidate(event, cacheName) {
  const cache = await caches.open(cacheName);
  const cached = await cache.match(event.request);
  const update = fetch(event.request).then((response) => {
    if (response.ok) return cache.put(event.request, response.clone()).then(() => trim(cacheName)).then(() => response);
    return response;
  });
  if (cached) { event.waitUntil(update.catch(() => {})); return cached; }
  return update;
}

// A response that came through a redirect cannot answer a navigation.
function clean(response) {
  if (!response.redirected) return response;
  return new Response(response.body, { status: response.status, statusText: response.statusText, headers: response.headers });
}

function withTimeout(promise, ms) {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(new Error('timeout')), ms);
    promise.then((r) => { clearTimeout(timer); resolve(r); }, (e) => { clearTimeout(timer); reject(e); });
  });
}

async function trim(cacheName) {
  const max = LIMITS[cacheName];
  if (!max) return;
  const cache = await caches.open(cacheName);
  const keys = await cache.keys();
  for (const key of keys.slice(0, Math.max(0, keys.length - max))) await cache.delete(key);
}
```

Things that must stay true if you edit this file:

- Pages stay **network first**. Never serve a cached page to an online reader.
- Only same-origin `GET` requests are handled. Cross-origin requests
  (Substack, LinkedIn, share links) pass through untouched.
- Only `response.ok && response.type === 'basic'` page responses are cached.
  Redirects (`opaqueredirect`) and 404s never are.
- Cache names start with `ainews-` (the offline page and the `activate`
  cleanup rely on that prefix).

## Step 9: CI check

Add `scripts/check_pwa.py` (stdlib only, like the other checks). It reads the
list of editions from `hugo.toml`, so adding a language needs no change here.

```python
#!/usr/bin/env python3
"""Check the built site is still an installable web app (Android "Install app").

Usage:
    hugo --minify && python3 scripts/check_pwa.py [PUBLIC_DIR]

For every edition in hugo.toml: the manifest exists, is valid JSON, has the
fields and icons Chrome needs, every icon it names was published, and the
edition's home page links it. Also checks the service worker and its offline
page were published. Exits 1 if any check fails.
"""
import json
import re
import sys
import tomllib
from pathlib import Path
from urllib.parse import urlparse

ROOT = Path(__file__).resolve().parent.parent
PUBLIC = Path(sys.argv[1]) if len(sys.argv) > 1 else ROOT / "public"
REQUIRED = ["id", "name", "short_name", "start_url", "scope", "display", "icons"]
ICONS = [("192x192", "any"), ("512x512", "any"), ("512x512", "maskable")]
MANIFEST_LINK = re.compile(r"""<link rel=["']?manifest["']? href=["']?([^"' >]+)""")

config = tomllib.loads((ROOT / "hugo.toml").read_text(encoding="utf-8"))
default = config.get("defaultContentLanguage", "en")
editions = ["" if lang == default else lang for lang in config["languages"]]

errors = []
for edition in editions:
    home = PUBLIC / edition
    path = home / "manifest.webmanifest"
    if not path.is_file():
        errors.append(f"{path}: missing")
        continue
    try:
        manifest = json.loads(path.read_text(encoding="utf-8"))
    except json.JSONDecodeError as e:
        errors.append(f"{path}: invalid JSON ({e})")
        continue
    for key in REQUIRED:
        if not manifest.get(key):
            errors.append(f"{path}: no {key}")
    if manifest.get("display") != "standalone":
        errors.append(f"{path}: display is not standalone")
    icons = manifest.get("icons", [])
    have = {(i.get("sizes"), i.get("purpose", "any")) for i in icons}
    for sizes, purpose in ICONS:
        if (sizes, purpose) not in have:
            errors.append(f"{path}: no {sizes} {purpose} icon")
    for shortcut in manifest.get("shortcuts", []):
        icons = icons + shortcut.get("icons", [])
    for icon in icons:
        if not (PUBLIC / icon["src"].lstrip("/")).is_file():
            errors.append(f"{path}: icon {icon['src']} not published")
    expected = f"/{edition}/manifest.webmanifest" if edition else "/manifest.webmanifest"
    link = MANIFEST_LINK.search((home / "index.html").read_text(encoding="utf-8"))
    if not link or urlparse(link.group(1)).path != expected:
        errors.append(f"{home / 'index.html'}: does not link {expected}")

for name in ["sw.js", "offline/index.html"]:
    if not (PUBLIC / name).is_file():
        errors.append(f"{PUBLIC / name}: missing")

for error in errors:
    print(error)
if errors:
    sys.exit(1)
print(f"Web app check passed for {len(editions)} editions.")
```

"Install Hugo" (Node is preinstalled on `ubuntu-latest`), and the web app check

```js
const { chromium } = require('playwright');
const { spawn } = require('child_process');
const [,, root, port] = process.argv;
const base = `http://localhost:${port}`;
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
(async () => {
  const server = spawn('python3', ['-m', 'http.server', port, '-d', root], { stdio: 'ignore' });
  await sleep(1000);
  const browser = await chromium.launch();
  const context = await browser.newContext();
  const page = await context.newPage();
  await page.goto(`${base}/sk/`);
  await page.evaluate(() => navigator.serviceWorker.ready);
  await sleep(1500);
  const cdp = await context.newCDPSession(page);
  console.log('installability errors:', JSON.stringify((await cdp.send('Page.getInstallabilityErrors')).installabilityErrors));
  const mf = await cdp.send('Page.getAppManifest');
  console.log('manifest:', mf.url, 'errors:', JSON.stringify(mf.errors));
  console.log('controlled:', await page.evaluate(() => !!navigator.serviceWorker.controller));
  const article = await page.evaluate(() => document.querySelector('.post-entry a.entry-link')?.href);
  await page.goto(article);
  console.log('caches:', JSON.stringify(await page.evaluate(async () => {
    const out = {};
    for (const n of await caches.keys()) out[n] = (await (await caches.open(n)).keys()).map((r) => new URL(r.url).pathname);
    return out;
  })));
  server.kill(); await sleep(500);                       // really offline: the server is gone
  for (const url of [`${base}/sk/`, article, `${base}/sk/archives/`]) {
    const r = await page.goto(url);
    console.log('OFFLINE', new URL(url).pathname, '->', r && r.status(), '| h1:',
      await page.locator('h1').first().textContent(),
      '| saved:', JSON.stringify(await page.locator('#saved li').allTextContents()));
  }
  await browser.close();
})();
```

## Rollback (kill switch)

A broken service worker keeps running in readers' browsers even after the
code is reverted. To remove it, **don't delete `sw.js`**. Replace its contents
with the version below, and remove the registration script in
`extend_footer.html`:

```js
// Retired service worker: clears its caches and unregisters itself.
self.addEventListener('install', () => self.skipWaiting());
self.addEventListener('activate', (event) => {
  event.waitUntil((async () => {
    for (const name of await caches.keys()) await caches.delete(name);
    await self.registration.unregister();
    for (const client of await self.clients.matchAll({ type: 'window' })) client.navigate(client.url);
  })());
});
```

Leave that file published for a few months. The manifest can stay: without
a service worker the site is still installable, it just stops working offline.

## Maintenance
