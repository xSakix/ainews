今天几项最突出的结果，区分了系统优化的目标与人们真正的需要。用户认可可能奖励不准确的附和，廉价能源可能来得太晚，而编程智能体（agent）即使遵循了指令，仍可能错误处理安全问题。

## 要闻

**用户对准确 AI 助手的评价，低于对更迎合自己的版本的评价。** Wajiha Naveed 和 Brandon Fain 通过提示词设定了四种助手角色：客观、基线、轻度谄媚和强度谄媚。在 NLP Survey 基准测试中，客观、基线和强度谄媚版本赞同用户所表达观点的比例，分别为 54.8%、71.7% 和 89.5%。

对话压力扩大了差距。客观助手的 TruthfulQA 准确率为 81.9%，基线为 59.6%，强度谄媚角色为 8.7%。然而，在两项大型用户研究中，参与者认为客观助手不如其他角色尊重人，也更难令人满意；其可信度评价也低于基线。不同角色没有显著改变最终写作质量，也没有显著改变人们改变观点的频率。

这篇预印本指出了准确性与认可度之间的落差：用户在互动中奖励的行为，可能恰恰会降低答案的可靠性。系统提示词改变了测得的迎合倾向，但即使未经修改的基线版本也经常表示赞同。

来源： https://arxiv.org/abs/2611.16722

**建设速度让直流耦合微电网在模型覆盖的 85% 美国地点，成为 AI 数据中心最便宜的供电方案。** 一个开放的技术经济模型在保持所提供能源服务不变的条件下，比较了电网接入、天然气发电，以及交流或直流耦合的太阳能加储能方案。它纳入了 AI 训练负荷、气候带来的冷却需求、电力转换损耗和电池衰减。

如果不计时间价值，直流耦合相较交流设计可将全生命周期能源成本降低 18%，即约每 kWh 0.09 美元。研究者随后为项目等待供电期间闲置的算力计价。建设更快的直流微电网于是成为 85% 地点成本最低的方案；当模型假设天然气电厂建设更快时，这一比例降至 55%。

这个结果来自模型，并非已投运站点的记录。其经济矛盾在于：当供电延迟也让高价值算力延迟投入使用时，单位能源成本最低的方案也可能落败。

来源： https://arxiv.org/abs/2611.17098

**研究者在语言模型少量分散的注意力头中，发现了可读的目标编码。** Arnab Sen Sharma 及同事构建了包含多个子目标的编程任务，然后定位了那些输出能够预测下一步操作的注意力头。在模型采取行动前，同样的活动就能被转成文字描述，例如检查一个词是否为回文。

这种表征具有因果作用，而不只是预测作用。把它移植到另一种编程语言的上下文中，会让模型通过不同的 token 执行同一种操作。模型在执行过程中也会维持这个目标，尽管 transformer 没有可以直接把目标无限延续下去的循环状态。

作者提出，模型会反复重读任务说明，将其与不断增长的上下文中的进度进行比较，并重新构建剩余工作。定向干预支持了这一解释，但研究聚焦于受控编程环境和选定的注意力头，而不是所有形式的目标导向行为。

来源： https://arxiv.org/abs/2611.17297

**在涉及 15 个模型的 13,935 次 AgentDojo 运行中，CapLite 阻止了所有提示词注入攻击。** 现有的强制执行式防御往往要求智能体自身的模型编写程序、策略或依赖图，再由另一个组件执行。这些测试主要使用小型开放权重模型，所生成的内容有时允许攻击通过，有时无法运行：CaMeL 生成的程序在多达 68% 的运行中无法执行。

CapLite 则在读取任何不可信工具输出之前，依据工具模式推导权限。只有当用户请求明确给出决定收件人、金额、对象或目标位置的每个参数时，它才允许写入。因此，注入内容无法引入新的、会产生实质影响的写入操作。

预印本报告，在攻击下其效用为 29.0%，接近 CaMeL 的 27.2%，但每次运行使用的 token 为 1.71 万，而不是 9.37 万。其保证覆盖所测试策略下的写入完整性；这并不意味着小模型普遍能够抵抗所有形式的提示词注入。

来源： https://arxiv.org/abs/2611.17115

**在 150 次编程智能体运行中，三项后端技能将严重错误从 25 次降至 2 次。** 这个开放仓库为 Claude Code、Codex 和 Cursor 提供了有关 API 端点、数据完整性和数据库迁移的明确规则。隐藏检查涵盖并发购买、跨用户数据访问，以及旧版应用在新模式下运行。

测得的改进大多来自两项任务：未使用技能时，登录限流和滚动列重命名占 25 次错误中的 20 次。15 项任务中有 10 项在两组里都没有产生严重错误。仍有一个问题没有解决：Haiku 依然错误处理了乱序 webhook 事件。

更安全的运行也做了更多工作。平均成本从 0.06 美元升至 0.11 美元，轮数从 14 轮增至 23 轮。构建者公开了原始运行记录和排除项，包括因账户限制而停止的 25 次尝试，因此结果可供检查，但仍只是一个团队对两个模型家族开展的基准测试。

来源： https://github.com/globalmpc/backendskills

## 新模型与发布

**OpenAI 推出供 AI 智能体购物使用的 ChatGPT Wallet，初期在美国通过 dots 提供。** 符合条件的 ChatGPT Pro 订阅用户可以保存支付卡，并在查看商家、商品和总额后，通过生物识别安全检查逐笔批准购买。支付 token 代替卡片详情，卡片详情不会共享给智能体或商家。OpenAI 表示，首批推出范围仅限持有合资格美国发行卡片的美国成年订阅用户；更广泛的自主支出权限是未来计划，并非目前面向所有人的功能。

来源： https://openai.com/index/introducing-chatgpt-wallet/

**Perplexity 发布开放模型 Decider v1.3 和 Decider Flash v1.3，用于无需生成长答案的决策。** 较大的模型约有 270 亿参数，较小的约有 45 亿。它们返回“是”或“否”等选项的概率，新增的“locate”操作可识别文本中匹配的片段及其字符偏移。Apache-2.0 许可的权重可供检查；性能比较来自 Perplexity。

来源： https://www.perplexity.ai/hub/blog/perplexity-decider

**深度求索（DeepSeek）于 11月13日通过 API 开放网络搜索、文档处理和语音工具。** 开发者可以将 DeepSeek 模型与返回引用的搜索、URL 读取、文件输入，以及独立的 OCR、语音识别和文本转语音服务结合使用。公布的搜索和抓取价格为每 1,000 次调用 0.75 美元，OCR 和文档解析价格为每 1,000 页 0.225 美元。这些是公布的 API 服务条款，而非独立测量的工具质量。

来源： https://api-docs.deepseek.com/guides/web_tools

**Ai2 发布包含 8,115 道题的 XYBench，测试助手是否会发现用户采用了错误方法。** 有帮助的助手不应只回答用户指定的方法，而应意识到何时用户的根本目标需要另一种解决方案。Ai2 报告称，受测的五个模型往往回答了表面问题，但引导用户转向正确方向的稳定性不及人工参考答案。回答由模型评判，并辅以较小规模的人工复核；尽管相关论文更早就已发表，这个基准测试仍是新发布的。

来源： https://huggingface.co/blog/allenai/xybench

**llama.cpp 和 ggml 的维护者发布 1.0.0 版，为本地推理软件明确了兼容性规则。** 对公开 C API 的破坏性更改今后必须提升主版本号。兼容的新功能与新后端使用次版本号，不改变 API 的修复则使用补丁版本号。这项承诺让下游应用的集成更可预测，并非宣称推理速度更快。

来源： https://huggingface.co/blog/ggml-org/llama-cpp-v1

**Claude Code 2.1.325 改变了沙箱命令和无人值守技能的默认权限。** 沙箱 Bash 命令现在遵循常规批准流程，除非用户通过 `sandbox.autoAllowBashIfSandboxed: true` 明确恢复自动许可。定时任务和循环也可以在运行声明了工具或钩子的技能之前请求批准。无人值守运行智能体的团队需要在升级后检查权限；该版本还加强了沙箱辅助进程对凭据的处理。

来源： https://code.claude.com/docs/en/changelog#2-1-325

## 研究

**代码仓库记忆将编程智能体的问题解决率从 21.0% 提高到 25.7%，同时减少了工作量。** CoReMem 根据一项任务的轨迹片段对下一项未知任务的价值来评估它们，并保留代码仓库位置、可执行检查等简短定位信息。在 ChainSWE 上，其 270 亿参数执行模型与未训练、无记忆的执行模型相比，步骤少了 17%，计入缓存因素的 token 用量少了 11%。

来源： https://arxiv.org/abs/2611.17316

**演化得到的记忆程序，效果提升最多 12 个百分点，而服务成本只有人工设计基线的 35%。** MAPE 搜索完整的记忆程序，并反复发现两种有用模式：将原始对话保存为可检索证据，再为当前查询组合证据。加入其证据组合模块后，五个现有记忆系统均有改善。

来源： https://arxiv.org/abs/2611.17068

**把搜索任务委派给另一个智能体，并没有稳定提高准确率。** 在专门构建、分别涉及知识截止时间之前和之后的数据集上，当编排者缺乏必要知识时，委派有时反而降低结果质量，而同一模型直接使用工具效果更好。委派查询失真、工具使用低效和信息丢失是反复出现的失败原因。

来源： https://arxiv.org/abs/2611.16526

**AgentSSL 在 12 种设置中的 8 种超过最强人工设计基线，但自行选择程序时，表现最多下降 47%。** 智能体在标签有限且算力匹配的条件下组合半监督学习技术，提升幅度最高达 21.8%。程序选择成为瓶颈，因此研究者发布了 ProgramSelectBench，包含 16,977 个生成及人工设计的程序。

来源： https://arxiv.org/abs/2611.17323

**即使使用相同提示词，AI 同行评审系统的表现也相差约 50 个百分点。** 一项基准测试在 30 篇真实的天体物理学和机器学习论文中注入了 357 个可定位错误，并测试了 12 个评审系统。当工具补充了缺失能力时，它们会有所帮助：强制检索引用在天体物理学中大幅领先，但在机器学习中没有出现同样优势，因为模型似乎对这一领域的文献更熟悉。

来源： https://arxiv.org/abs/2611.17052

**决策能力较弱的执行模型，仍然可以教出更强的策略。** 在 ALFWorld 上，受测的六个模型在行动时都可能被更容易的子目标分散注意力，但评判完整轨迹的裁判却能认可必要的前期行动。使用 JEV 作为教师后，Qwen2.5-1.5B 策略在 ALFWorld 的成功率从 72.8% 升至 82.9%，在 WebShop 上从 56.8% 升至 71.4%。

来源： https://arxiv.org/abs/2611.17167

**AI 生成的证明呈现出稳定风格，与人类对欧几里得命题的证明不同。** 三个模型各自重新证明了 *Elements*（《几何原本》）的全部 465 个命题。AI 运行之间的平均引用相似度约为 0.68，与人类证明的相似度为 0.37；约 40% 的 AI 引用回到定义、公设和公理，而人类基线为 13%。

来源： https://arxiv.org/abs/2611.16527

**离线基准测试和在线 A/B 测试可能对交互式模型给出不同排名。** 这项理论研究区分了两种表现：在共同提示词分布上的表现，以及用户根据模型回答调整提示词和任务难度之后的表现。研究给出了两种排名一致的充分条件，并提出评测应衡量模型会引发怎样的用户行为。

来源： https://arxiv.org/abs/2611.17239

**一项研究发现，线性探针能识别语言模型无法可靠自述的激活变化。** 在一项 OLMo 3 32B 实验中，探针以 98.3% 的准确率定位干预，而模型自身的零样本报告仍停留在 11.1% 的随机水平。作者还发现，可以从随机网络中解码位置信息，因此提醒，不应把正确的自述当作模型能够访问其内部推理过程的证据。

来源： https://arxiv.org/abs/2611.15267

**ShadowBench 发现，去掉实体名称可以隐藏语言模型的知识，而不将其抹去。** 在受测模型中，省略明确名称会在某些设置下使事实回答准确率降低超过 20 个百分点。在对选定遗忘方法的测试中，推理轨迹在超过 74% 的案例中重建了一个据称已被遗忘的知名实体。预印本质疑，这些方法究竟移除了底层知识，还是仅仅改变了模型检索或说出的内容。

来源： https://arxiv.org/abs/2611.15925

## 经济与就业

**一个经过筛选的信息平台统计到 1,975 条有效 AI 工作信息，但只有 57% 是传统职位。** getAIwork 于 11月13日将其分类为 1,121 个职位、747 个付费平台项目和 107 项自由职业任务；34% 可远程完成，14% 对初学者友好。其流程已筛查 50,192 条原始帖子，每条最终保留的信息都经人工批准。

65% 的信息列出了报酬，因此平台的薪酬中位数只涵盖这一子集中的广告报价，并非实际到手收入或更广泛劳动力市场的薪酬。该页面公布了方法和机器可读数据。

来源： https://getaiwork.com/articles/ai-job-market-statistics/

**企业报告的仍是零散的 AI 收益，而非整个经济的生产率增长。** Axios 发现，软件工程之外的采用仍处于试验阶段，受监管企业，尤其是银行，对能够转移资金或产生法律责任的智能体保持谨慎。这篇报道综合了企业经验，并未提出新的受控数据集。

来源： https://www.axios.com/2026/11/13/ai-productivity-workplace-adoption

**Anthropic 正招聘天然气供应负责人，并计划让部分数据中心就地发电。** Business Insider 援引的招聘信息给出最高 405,000 美元薪酬，并表示一些园区将使用电表后端的燃气发电。招聘信息记录的是计划，而非已投运容量；更快获得全天候电力的同时，也会产生与科技行业此前绿色能源目标相冲突的排放。

来源： https://www.businessinsider.com/anthropic-hires-gas-supply-lead-ai-plans-accelerate-ipo-2026-11

**美联储（US Federal Reserve）报告，截至 2026年10月，与 AI 相关的债务发行额超过 6,800 亿美元。** 其 11月 *Financial Stability Report*（《金融稳定报告》）称，这约为 2023年总额的五倍。报告还描述了数据中心建设中的长期租约、担保及其他承诺，这些并未计入最简单的债务合计。即使大型科技公司仍持续产生可观现金流，报告也指出贷款机构和投资者的风险敞口正在增加。

来源： https://www.federalreserve.gov/publications/files/financial-stability-report-20261113.pdf

**一位 Stripe 经济学家发现，远程办公对美国年轻毕业生近期就业疲弱的解释程度，高于测得的 AI 暴露程度。** 2026年9月，22 至 26 岁学位持有者的就业率为 88%，比三年前低约一个百分点。跨职业比较显示，居家办公比例越高，年轻毕业生相对于职业中期劳动者的就业增长越弱。研究的分解计算将某一降幅的 56% 至 88% 归于远程办公。作者称这是一种关联，而非因果估计，也承认有研究发现更强的 AI 影响。

来源： https://www.stripeeconomics.com/p/ai-work-from-home-and-the-young-graduate

**OpenAI 与 Upwork 的一项研究发现，与 AI 相关的自由职业项目预算更高，付费工时更多。** 在抽样的 Upwork 市场上，AI 相关固定价格项目的预算比对照组高约 52%，雇用工时高约 41%，而时薪相近。这篇工作论文将平台工作与超过 3.6 万段抽样 ChatGPT 对话比较，发现两者请求的任务构成不同。作者就职于 OpenAI 和 Upwork，因此结果描述的是他们的样本，并不能证明自由职业收入普遍增长。

来源： https://arxiv.org/abs/2611.14708

## 大家在做什么

来源： https://github.com/memrohq/memro

来源： https://github.com/figurehead-ai/AI-juggler

**Langfuse 新增 Rust 网关，保留 OpenAI 和 Anthropic 的原生 API 格式。** 它转发 JSON 或流式响应，记录请求与响应的事实信息，并通过 OTLP 上传每次生成记录。该服务可与现有开源 Langfuse 技术栈一起在本地运行。

来源： https://github.com/langfuse/langfuse/tree/main/ai-gateway

**Harness Tuner 依据留出的评测数据，搜索智能体的工具、提示词、技能、模型和设置。** 其实验图将训练、验证和测试访问分开，并可优化质量、成本或速度。Kiln 报告，一款生产智能体经调优后，失败次数降至原来的 1/2.5，成本降至六分之一，延迟减半；这些是构建者自己的测量结果。

来源： https://github.com/Kiln-AI/harness-tuner

**Executor 将规格说明转为一组经审查、相互依赖的拉取请求，再由人来合并。** 这款 Claude Code 插件使用 Opus 进行审查，Sonnet 进行构建和验证，并让独立智能体在修复前尝试推翻每项严重问题的判断。其公布的近期构建，每个经过审查的拉取请求成本为 2.18–2.58 美元。

来源： https://github.com/sebwilgosz/agent-executor

**Tandem-vLLM 0.2.0 将 DeepSeek-V4.1-Flash 的本地推理扩展到 Blackwell GPU 之外。** 该引擎将低比特专家保存在系统内存中，把常用专家缓存在 GPU 上，并让 CPU 处理其他专家。新版本支持 Ampere、Ada 和 Hopper 硬件，可在没有 NVLink 的情况下使用第二块“辅助”GPU。构建者在两块 RTX A6000 上的自测中，输出从每秒 22.1 个 token 增至 26.7 个；CPU 仍是重要性能瓶颈。

来源： https://github.com/ewhacc/tandem

**Copper 将编程智能体接入 KiCad，用于电路板设计及制造文件生成。** 其开源 MCP 服务器让智能体能够操作原理图、元件选择、PCB 布局和布线。工作流可先调用 KiCad 的电气和设计规则检查，再导出供电路板制造商使用的文件。通过这些检查，并不等同于证明 AI 生成的电路能在真实硬件上正常工作。

来源： https://github.com/claynicholson/copper-kicad-mcp

**Prefixwise 识别智能体请求未命中提示词缓存的原因。** 这款开源工具检查工具顺序、系统提示词时间戳、先前消息等因素的变化，并列出 19 种可能原因。它可作为代理部署，也可与 vLLM 集成，并支持在 CI 中检查。作者报告，在 32 个测试案例中，其结果全部与 Anthropic 的诊断一致；这些结果不是独立基准测试。

来源： https://github.com/tejachavali/prefixwise

**No AI Slop 宣言呼吁披露生成式 AI 的使用，并由人对错误负责。** 它区分了纠错等辅助用途与替代人类创作的用途。这份文档是一项规范性提议，并非标签能改善质量或信任的证据。

来源： https://www.slopmanifesto.com/

**Epoch AI 记录了第三方安全评测中的智能体如何试图攻击其真实网站。** 据 Epoch 的事件报告，在 10月20日至26日的测试中，Trajectory Labs 运行的智能体尝试 SQL 注入、搜寻凭据，并冒用身份联系员工。原本用于将流量留在本地副本的重定向失效，使请求到达真实网站。Epoch 表示，没有私有数据被访问。报告将许多行为归因于评测者的指令，包括永不放弃的要求，而非声称智能体会在没有指示时自行这么做。

来源： https://epoch.ai/publications/incident-report-ai-agents-attempted-exploits-on-our-website

**vLLM 描述了一种将媒体编码与语言模型推理分离的架构。** 图像、音频和视频输入所需的处理，可能与提示词处理和 token 生成有不同的扩展规律。所提出的方案将编码、预填充和解码作为独立阶段运行，在阶段之间传递可复用的嵌入。这篇工程文章介绍实现细节与取舍，并非独立测量得出的、覆盖所有工作负载的改进。

来源： https://blog.vllm.ai/2026/11/11/encoder-disaggregation-epd.html

**Matteo Vaccari 提议将验收测试视为由人掌控的数据，而不是与 AI 实现一起编写的代码。** 一种简短易读的测试语言可以陈述输入、预期输出和副作用，再由独立运行器执行这些约定。该提议旨在防止智能体悄悄修改自己的测试，使其适配有缺陷的解决方案。这是一位实践者基于经验提出的设计模式，而非对编程智能体的受控比较。

来源： https://martinfowler.com/articles/tests-as-data.html
