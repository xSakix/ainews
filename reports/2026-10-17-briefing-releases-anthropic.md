- NVIDIA releases Nemotron Labs Dory 1.0 4B, a looped model that reuses one block of layers several times per token — Dory (OpenMDW-1.1 licence, 256K context, English) puts 8 input layers and 8 output layers around a 20-layer shared recurrent block that is applied 1, 2 or 4 times, so one checkpoint trades inference compute for accuracy without retraining; "last-loop" KV caching keeps cache memory at the one-loop size. It was pre-trained natively in NVFP4 (4-bit) before continuing in BF16. On NVIDIA's own table, 1, 2 and 4 loops score SWE-bench Verified 50.3, 59.5 and 61.8 (Qwen3.5-4B 54.7, Qwen3.5-9B 61), Terminal-Bench 2.1 12.5, 18.1 and 22.2, and IFBench 74.3, 77.9 and 79.0 (Qwen3.5-4B 53.8). It trails Qwen3.5-4B on GPQA Diamond (72.4 at two loops against 77.7) and on HLE text-only (10.9 against 11.3), so the gain is concentrated in agentic and coding tasks. The card says looping needs fewer generated tokens and recommends two loops as the default. Support in vLLM and llama.cpp is still in open pull requests (vLLM #60149, llama.cpp #30306), so it does not run in released versions of either today.

## 2. Europe

- Kyutai (with Inria and École nationale des ponts et chaussées) releases REKI-2B, a 2.4B robot policy with a cheap memory, plus four fine-tuned variants and the full code — A vision-language-action model (Qwen3.5-2B vision-language backbone plus a 0.2B flow-matching action expert) pre-trained only on public data: 1.0B frames of robot teleoperation, simulation and human egocentric video plus 12.2M vision-language samples. Its memory is 32 register tokens per frame cached across the last three frames, which the authors say adds under 1% to chunk prediction time, raises success by 1.5 to 5.5 points on three benchmarks and makes oscillation between poses about four times rarer. Kyutai reports 21.8 ms per action chunk on one H100 and the best public-data-only scores on RoboTwin Clean2Rand (65.8) and LIBERO-Plus (90.4); these are the authors' figures. Weights are CC BY-NC-SA 4.0 (non-commercial) and code is MIT, so the release is open for research but not for products. The paper was submitted to arXiv on 15 October and the weights were opened 16 October.

## 3. China

- Tencent Hunyuan releases Hy-Memory-30B-A3B, a small mixture-of-experts model that only does one job, deciding what an agent's long-term memory should store — Roughly 3B active parameters (30B total, Apache 2.0, English and Chinese), trained in two stages (on-policy distillation of write protocols, then reinforcement learning with per-chunk probes and over-storage controls) to replace the general-purpose model inside the memory frameworks Mem0, MemOS and Tencent's own Hy-Memory. In the technical report (arXiv, 15 October) it averages 55.49 across four memory harnesses against 54.62 for Claude Opus 5 and 53.64 for DeepSeek V4.1 Flash, including a harness (EverMemOS) held out from training. The margin is under one point, the scores come from fixed 20% subsamples of the benchmarks, and Opus 5 wins several individual metrics (for example LoCoMo on the Mem0 harness, 69.5 against 59.5), so the claim is a cost argument, a 3B-active writer matching a frontier model on this task, not a capability lead. Of interest to the reader because memory writing is where agent products pay a per-token cost on every turn.

- Tencent opens the inference code and a Qwen3-8B checkpoint of DSpine, a parallel drafter for speculative decoding — Weights are labelled Apache 2.0 and uploaded 16 October; the paper ("Draft in Parallel, Condition Through Depth", arXiv 2609.36173) appeared in September, so the new element is the runnable code and checkpoint. The drafter proposes all positions in parallel while passing each position's predicted feature to its successor at every draft layer. On Qwen3-8B the authors' table shows average acceptance length of 7.83 at temperature 0 and 6.98 at temperature 1 against 7.55 and 6.53 for DFlash2 and 7.44 and 6.65 for DSpark (all retrained on the same data), a gain of about 4 to 7%. Practitioners who serve Qwen3-8B can try it, but the improvement over the previous drafters is modest and acceptance length is not wall-clock speed-up.
