## 1. United States

- **Percepta publishes Spotlight, a memory architecture that replaces attention with an unbounded, sparsely indexed memory** — Percepta Research's 2 October post describes a model in which every token reads from and writes to a memory that can grow without limit. The model learns to index individual memory cells, so each token touches a fixed small number of them however large the memory gets. This differs from mixture-of-experts, where the active fraction of a fixed capacity is set in advance. The post also separates an "intelligence" module (compute) from the memory, so knowledge and skills could grow without changing the weights. A companion post on 2 October, "Can LLMs Grow Their Own Capabilities?", gives the motivation. The pages render client-side and I could not read benchmark numbers, a paper, code or weights from them. The claims, including "first architecture to achieve infinitely growing memory without increasing the access cost", are Percepta's own. LocalLLaMA commenters compare it to neural Turing machines and differentiable neural computers, and ask where the claims can be tested.

## 5. Tools, APIs and platform updates

- **NVIDIA announces DGX Spark with 64GB of unified memory, shipping from partners on 23 October, plus a cluster assistant for pairing two units** — The new configuration keeps the GB10 Grace Blackwell Superchip, ConnectX-7 networking and the DGX OS/CUDA software stack of the 128GB model. NVIDIA says it runs models of up to 100B parameters locally, and that two units linked by QSFP cable through the NVIDIA Sync Cluster Assistant pool 128GB and support up to 200B parameters. In NVIDIA's own Qwen 3.8 27B test, two clustered 64GB units reached up to 1.7x the throughput of one. The 64GB SKU is sold only through Acer, ASUS, Dell, Gigabyte, HP and MSI. The post gives no price. For local-model builders it is a cheaper entry point for the same software stack, but all performance numbers are NVIDIA's.
