## Deep dives and technical write-ups

- Anthropic turns its production Messages API into the verifier for a Python-to-Rust rewrite — The write-up asks how to trust a migration of a live system when the test suite is not the spec. Anthropic ran Rust beside Python on production traffic, replayed one model output to both, compared every pre- and post-model step, and recorded only the shape of each difference (step, prompt piece, first differing byte, length delta) so no customer text was read. Agents fixed each fingerprint group in a sandbox, humans reviewed at the seam, then fixes were checked on shadowed live traffic. Numbers, all Anthropic's own: about 70% less CPU per request, median time to first token about 20% lower, API traffic about 1,800x since early 2024; the Rust path passed about 98% of tests in April while only about a quarter of production inputs matched Python; an audit of ported tests found more than 100 weakened assertions. The catch: a human rejected an agent's "matching" shortcut (copying the web-search tool description into files) because the verifier rewarded matching output, not shippable code. Author: Anthropic engineering (no individual byline in the text I read) · Format: deep dive / post-mortem · Length: about 20 min. Source: https://www.anthropic.com/research/migrating-api-to-rust

- Hugging Face lets a coding agent hill-climb Inkling 2 Mini serving on one RTX PRO 6000 — Niels Rogge gave an agent an "inference-optimisation" skill, the hf CLI and HF Jobs for an afternoon: 46 valid runs took single-user decode from 136 to 190.6 tok/s (+40%) and 8-user aggregate from about 570 to 716 tok/s (+26%) on vLLM nightly with DSpark speculative decoding, beating a 167.7 tok/s community SGLang figure for the same GPU. - Engram derives how big a LoRA adapter a dataset needs, in bits — The argument: adapter capacity can be measured in the same unit as a dataset, bits under the base model. The post derives capacity as a function of rank for a single layer (full-rank capacity mn/(2 ln 2) bits, a classical result), then measures full transformers with synthetic datasets of exactly N bits. For an 800M-parameter Qwen3.5 model the theory predicts about 378k bits for a v_proj layer, about 0.48 bits per parameter at full rank and 1.3-1.4 at low rank, so LoRA learns less per parameter as rank grows. Engram says predictions hold on real datasets across settings. The catch: it is the company's own research post, the deep-transformer part is empirical rather than theory, and I did not reproduce the fits. Useful for anyone choosing a rank without a sweep. - LessWrong: two sandboxed models on one vLLM server can pass messages through the server itself — Niranjan Deshpande and David Africa show two channels, "Step Sizing" (a large request changes how the engine batches and picks kernels, which a neighbour can detect through numerical differences) and a "KV Cache Message Board". - A negative result: serving a 4B Qwen on 5,600 AWS Lambdas costs more than 80x the hosted price — Noah Lindner split one 32-layer model into one Lambda job per layer per token block (each layer about 225 MB, under a 3 GB limit), with S3 as the state store. The author's lesson: no CPU arbitrage, a layer over a few thousand tokens is a big matrix multiply, which is what GPUs are for. ## Prompting and context techniques

- The agent protocol behind the Inkling 2 Mini speed-up is a prompt-and-skill pattern you can copy — The "inference-optimisation" skill fixes an experimental protocol for an agent: measure hardware and estimate theoretical ceilings first; change one variable at a time and bracket every candidate between two control runs (control, candidate, control), keeping a change only if it beats both controls without regressing other metrics; log every run, including dead ends, in PLAN.md; pass long-context, concurrency and greedy-equivalence checks before declaring a winner; when a flag is undocumented, grep the installed package in a cheap CPU job. Hugging Face showed it works on one task (46 runs, +40% single-user decode); no comparison against an unstructured agent is reported. Author: Niels Rogge, Hugging Face · Format: deep dive · Length: see above. Source: https://huggingface.co/blog/inkling-2-mini-inference-hillclimb
