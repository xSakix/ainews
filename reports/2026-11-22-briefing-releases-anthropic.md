## United States

- Ai2 releases ACE2.5-ERA5, a 46M-parameter climate emulator — Ai2's climate emulator family gets a stochastic successor to ACE2-ERA5 (456M parameters): calibrated ensemble predictions from days to centuries, 10x fewer parameters and 3.2x faster inference. Ai2 reports ensemble spread matching error to within 4% from day 3, and 86% of ERA5's spectral power retained at wavenumbers 100-179 (ACE2-ERA5: 36%). Three checkpoints are released (1° daily 46M, 4° daily 14M with 5x throughput and 10x lower training cost, 1° 6-hourly 46M), plus seeds 1-3 and ablations. Limits stated by Ai2: the daily model's medium-range weather skill is below ACE2-ERA5 (the 6-hourly one matches it), the separate SST and CO2 sensitivities are not realistic, global-mean temperature variability is uncalibrated, and it is a research tool, not for operational prediction. All results are the lab's own. Artefacts: weights (Apache-2.0) / code (fme) / reference data bucket / paper reproduction scripts · Sizes or variants: 46M (1° daily), 14M (4° daily), 46M (1° 6-hourly) · Released: 19 Nov 2026 (HF repo created 19:30 UTC). Source: https://huggingface.co/allenai/ACE2.5-ERA5

## China

- inclusionAI (Ant Group) releases LingSante-Pulse-1.0, a physiological-signal encoder — a 16.7M-parameter encoder for time-series signals such as ECG, taking input at 128 Hz and returning 256-dimensional CLS and patch-mean features per channel (patch features every 0.25 s). It is an encoder only: no task-specific prediction heads are shipped, and the card gives no benchmark figures, so its quality is unverified. Channel identity vectors come from BAAI/bge-small-en-v1.5; inference needs a separate code package. Of interest as a small, MIT-licensed health-signal foundation model from the Ling team. Artefacts: weights (MIT) / code package separate / no technical report linked on the card · Sizes or variants: 16.7M parameters · Released: 20 Nov 2026 (HF repo created 08:39 UTC). ## Tools, APIs and platform updates

- OpenAI ships GPT-Live-1.1 in the Live API — the update improves pronunciation, accent consistency and transcription in multilingual voice conversations, and can be used in an existing Live session config via `gpt-live-1.1`. A standby mode for GPT-Live-1 and 1.1 WebRTC sessions pauses inference while nobody speaks and resumes on speech, which should cut the bill for idle sessions (no price figure given in the changelog). The improvement claims carry no numbers and are OpenAI's own. Artefacts: API only · Sizes or variants: gpt-live-1.1 · Released: 19 Nov 2026. Source: https://developers.openai.com/api/docs/changelog

- Codex 0.171.0 adds the GPT-6.2 model catalogs with Sol as default — the release (20 Nov) adds GPT-6.2 Sol and Astra to the model list with Sol as the default, enables the TUI workspace by default, and adds `codex exec --remote <ADDR>`, `/rc` and `/remote` commands and `/statusline` customisation. - Ai2 open-sources Theorizer in Asta — a research agent in Ai2's Asta platform that proposes candidate scientific theories from the literature. In Ai2's examples it returned 50 candidate theories on VIP interneurons where the researcher expected one or two; the cited use cases are neuroscience, a Peru climate study (17,027 grid cells), potato diversity records and lung adenocarcinoma (about 20-30% of cases lack a recognised driver alteration). Ai2 itself warns it can miss relevant studies and misjudge originality, and the lung cancer findings need experimental validation. The web interface covers token costs up to a limit; the open library runs locally with the user paying tokens.
