## 1. Safety and security

- AutoGPT: nine new advisories in one day, including one where a shared agent's author can use the credentials of whoever runs it — NVD published nine CVEs for the AutoGPT agent-workflow platform on 25 Nov, all stated as fixed in 0.11.0 (some in 0.10.0). The most serious, CVE-2026-133462 (CVSS 3.1 score 8.7, scored by the GitHub advisory source), says the MCP tool block's auto-lookup lets the author of a shared agent use the MCP credentials of any user who runs it, if that user had already connected the named MCP server. Others cover an unbounded ZIP-thumbnail expansion in Office previews that can exhaust an API worker's memory (CVE-2026-133459) and pricing blocks that run LLM, code and image calls free for an account with zero credit when a priced input is left at its default (CVE-2026-132255). The catch: these are authenticated-user and shared-agent attacks, the scores are the reporter's, and no exploitation in the wild is reported. The lesson for agent builders is that shared agents plus stored tool credentials create a confused-deputy risk. Source: https://services.nvd.nist.gov/rest/json/cves/2.0?keywordSearch=artificial%20intelligence&pubStartDate=2026-11-25T00:00:00.000&pubEndDate=2026-11-26T23:59:59.000

Together they show that an "approved read-only command" allowlist and a local MCP port are the weak points in agent tools.
