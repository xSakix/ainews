🚨 GPT-6.2 Astra and GPT-6.2 Sol (OpenAI) — OpenAI released a new pair of flagship models on 17 November, available in ChatGPT Work, Codex and the API. OpenAI's announcement claims better professional outputs, coding, computer use and efficiency "at lower cost". The API docs make the cost part checkable: Astra is $8 per million input tokens and $40 per million output, down from $10 and $50 for GPT-6 Astra in OpenAI's pricing table, a 20% cut. Sol stays at $2 / $10, the same list price as GPT-6.1 Sol. Neither model accepts reasoning effort "none". Long requests (over 272K input tokens) double input rates and raise output 1.5x; Batch is half price and "ultrafast" is 3x standard through 28 February 2027, then 6x. The migration guide carries a change that affects bills: from GPT-6.2 the API drops reasoning items when it detects prefix edits, a model downgrade or a change of end user or organisation, so answer quality can fall and token use rise unless integrations keep the prefix unchanged. The announcement page itself returned 403 to direct fetches; the specifications below come from the API docs. Benchmark claims are OpenAI's own. FastFrames: interactive-latency video generation (Apple) — Apple researchers released FastFrames-S (1.3B) and FastFrames-L (14B), autoregressive two-step video diffusion models producing 480p video in under 50 ms per frame. They profiled existing pipelines and found that VAE decoding and KV-cache updates, usually treated as fixed, account for over half of end-to-end latency, and replaced them with lightweight alternatives. Apple's claims: 36 ms per frame (28 responses per second) on one B200 for the 1.3B model, matching the quality of a state-of-the-art model nearly 8x slower; 45 ms (22 RPS) for the 14B on an 8x B200 node; a 16x speed-up of the third-party LingBot 1.3B for camera control. The model card says the arXiv paper is "coming soon", so the figures are not yet independently checkable, though latency profiling and VBench scripts are in the repository. Artefacts: weights (apple-amlr licence, based on Wan2.1-T2V-14B), code, project page · Sizes or variants: 1.3B and 14B · Released: Hugging Face upload 16 November 2026 Source: https://huggingface.co/apple/FastFrames-L
